# 供应链

用脱敏的历史样例数据体验订单欠货、接单承诺、BOM、库存、采购跟进和交期分析，包含 12 张数据表、本体、原生函数和业务 Skill。业务需求与口径见 [PRD](docs/PRD.zh-CN.md)。

## 安装与体验

1. 登录 OpenBKN，进入首页的**一键体验**。
2. 刷新官方目录，选择**供应链**并点击**安装**。
3. 等待安装和验证完成，打开对应知识网络。
4. 在智能问答、数据查询和图探索页面试用体验卡，或接入外部 Agent，通过 MCP 查询对象、调用已发布函数和使用 Skill。

无法访问官方目录时，从 [Releases](https://github.com/openbkn-ai/bkn-samples/releases) 下载供应链的 `package.tar.gz`，在一键体验中选择**导入离线包**，导入后安装。包引用的数据镜像也必须在目标集群可用；受限网络环境请由管理员提前准备该镜像。

安装无需用户配置 Python、CLI 或数据库连接。详细操作与验收见[安装与验收指南](docs/openbkn-hand-import-guide_cn.md)。

样例是历史回放，不代表实时库存或真实交付承诺，不会自动创建采购订单或写入 ERP。

## 能力

能用 Cypher 查到的不写函数，只为 Cypher 表达不了的计算保留函数。样例不使用指标，社区版即可完整使用。

- **Cypher 查询**：主数据、库存汇总、欠货与逾期、预测、在途与逾期采购、BOM 清单（从产品出发一次取得整棵 BOM，按层级和父件过滤）、反查用途、通用料、单据追溯。平台不支持变长路径和 `UNWIND`，Skill 中给出对应写法。
- **原生函数**：
  - 齐套与可做数量：按 PRD 口径逐层净扣，可按需求日期计入在途，返回能否满足、缺料清单和最大可做数量。
  - 多需求共享库存：按给定顺序在同一库存池上依次评估多张需求。
- **Skill**：按 PMC 计划和采购跟进两类使用者组织，写明业务口径、何时用 Cypher、何时调用函数、必须问清的条件和回答格式。

## 体验卡

体验卡从测试集中选题，每个场景 1–2 张，约 15 张，由浅入深：先查数（欠货、库存），再追关系（反查用途、单据追溯），最后做推理（能接多少、卡在哪、该催谁）。卡片的数据查询和图探索 Cypher 用 `tools/acceptance/experience_set.py` 在安装后的平台上在线核验。

## 验收与维护

测试集见 [v4 业务场景测试集](bkn-eval/baselines/2026-10-30-business-scenarios-v4/README.md)，参考答案由独立脚本从交付数据计算，不随安装包交付。安装后让未读答案的智能体每题跑一轮；未达 100% 时记录失败原因，先改本体描述、Skill 或函数，不改题目和答案迁就结果。

升级时先卸载旧样例，再安装新版本。卸载会清理样例数据和用户修改；删除离线包缓存不会卸载已安装资源。

开发者可查看 `sample.yaml`、`db/`、`platform/` 和 [tools/](tools/README.md)。这些脚本由标准安装 hooks 调用，客户和伙伴不需要逐个执行。
