# 第三方 Agent 数据交接说明

面向体验 `供应链原生计算函数` 工具箱的第三方 Agent。工具箱提供按业务命名的函数，例如“BOM 清单”“物料反查产品”“合计可售”“生产计划齐套倒排”。Agent 只提供**业务参数**；函数在 OpenBKN Function Runtime 内通过官方 `sandbox_sdk.bkn` 自行读取供应链知识网络数据并计算。

第三方无需配置函数服务器地址、数据库地址、MCP 地址，也不需要保存 Toolbox UUID、数据快照或回执。部署管理员负责一次性完成样例导入、工具箱发布及平台连通性配置。

## Agent 的简单流程

```text
bkn_start_interaction
→ 通过 OpenBKN MCP 的 tools/list 发现可用函数及参数
→ 通过 MCP 调用合适的具名函数，只传业务参数
→ 根据结果形成业务答复
→ bkn_finish_interaction
```

## 先按问题复杂度选择能力

```text
简单事实 / 查询 → 直接查对象、关系或指标
单一确定性计算 → 直接调用具名函数
多步骤业务场景 → 使用 Skill 导航指标、函数、澄清项和业务结论
需要受控行动 → 人工确认后调用 Action
```

Skill 不是简单问题的必经入口。例如“有多少供应商”优先使用指标，“某物料标准交期多少天”直接调用标准交期；只有“客户需求能否按某日期履约”或“多个客户需求能否一起承接”等跨能力业务场景才使用 Skill。

1. 一轮业务对话开始时调用 `bkn_start_interaction`，保存返回的会话信息。
2. 用 OpenBKN MCP 的 `tools/list` 列出已发布函数及参数，选择最贴合问题的具名函数；事实查询、Interaction 生命周期、Skill 发现和函数执行均走 MCP。
3. 调用函数时携带本轮 Interaction 的受管上下文，并只传该函数说明中的业务参数。复杂计算优先使用函数；不得以 CSV、数据库直连或本地金标替代函数结果。
4. 完成答复后调用 `bkn_finish_interaction`。出错、函数不可用或结论无法取得时，如实说明原因。

函数自行读取所需对象数据。运行时通过 `sandbox_sdk.bkn` 调用官方 Context Loader；平台会在受管调用中内部处理身份、会话和 MCP 地址。Agent 不需要也不应把 Token、服务地址、数据快照或 `resolved_context` 作为函数参数传递。

## 责任边界

| 角色 | 负责 | 不负责 |
|------|------|------|
| 第三方 Agent | 发起/结束 Interaction；发现工具；传入业务参数；解释结果 | 拼装数据快照、传递凭据、配置集群地址 |
| 原生函数 | 按函数口径读取业务知识网络；完成计算；返回结论与取数范围 | 读取 CSV、依赖调用方传全量 BOM / 库存数据 |
| 平台管理员 | 导入样例数据；绑定知识网络；发布函数；保证 Sandbox 到 Context Loader 的连通 | 为每次业务问题手工准备数据 |

**不要自行封装 Context Loader。** Agent 直接使用宿主提供的 OpenBKN MCP。函数内部的知识网络访问由官方 SDK 管理，不能改成自行拼接 HTTP、账号 ID 或服务地址。

## 示例：合计可售

问题：产品 `382-000005`，不启用替代料，目前最多可销售多少？

先完成 `bkn_start_interaction`，然后从 `tools/list` 发现“合计可售”函数并调用：

```json
{
  "product": "382-000005",
  "substitute_enabled": false
}
```

函数会自行读取产品 BOM 与库存，返回成品可用量、理论可产量与合计可售量。Agent 据此解释结论并结束 Interaction。

## 函数选择提示

| 业务问题 | 优先函数 |
|------|------|
| 查产品结构或子件 | BOM 清单、子料分层库存 |
| 判断可生产或可销售数量 | 理论可产、合计可售、无需采购最大可产 |
| 判断需求是否齐套 | 要 X 套净需求与齐套、生产计划齐套倒排 |
| 判断多产品争用 | 共用料与多需求争用、产品 BOM 共用清单 |
| 查交期或单料供应风险 | 标准交期、供应状态诊断 |
| 查预测单状态 | 未关闭预测单数 |
| 某物料短缺会影响哪些产品 | 物料反查产品 |

结果使用规则：问“列出缺料”时，`要 X 套净需求与齐套` 默认已在 `gaps` 返回全部缺料；若报告只展示部分，必须注明“展示前 N 项，共 X 项”。向采购提出数量建议时，只使用缺料项的 `recommended_replenishment_qty`，它等于当前需求快照的净缺，不包含 MOQ、安全库存或其他订单的加量。

数据基线、业务日期及每个函数的业务口径见 [能力口径清单](./能力口径清单.md)。CSV 只用于样例离线回归，不是运行时数据源。

## 发布前管理员检查

发布给第三方前，管理员应确认：供应链样例已导入并绑定数据资源；所需业务函数均为 enabled；Function Sandbox 已配置到官方 Context Loader 的集群内连接；以一轮真实 MCP Interaction 调用任一函数能获得结果和可回读 Trace。未通过该检查时，不要让 Agent 用本地计算替代线上函数。
