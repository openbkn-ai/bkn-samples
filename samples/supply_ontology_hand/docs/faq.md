# 常见问题

**从哪里安装？** 在 OpenBKN 首页进入一键体验，刷新官方目录后选择供应链安装。无需用户自行配置 CLI、Python 或数据库。

**不能访问官方目录怎么办？** 从 [Releases](https://github.com/openbkn-ai/bkn-samples/releases) 下载对应版本的 `package.tar.gz`，使用导入离线包。离线包引用的数据镜像也必须在目标集群可用；受限网络环境请由管理员提前准备。

**安装失败怎么办？** 查看失败详情，保留样例版本和错误信息。修复环境问题后重试原安装记录；若提示原始 manifest 不匹配，请联系管理员，不要用手工脚本覆盖。

**函数或 Skill 不可用怎么办？** 通过 MCP 查看实际发布状态及调用错误。请管理员检查安装记录和调用者权限。原生函数只接收业务参数，不需要调用者提供凭据或 `resolved_context`；不能用本地计算代替实际调用。

**如何更新版本？** 先卸载旧样例，再安装新版本。卸载会清理样例数据和用户修改。删除离线包缓存不等于卸载。

**业务标识怎么处理？** 产品、订单、预测等标识作为字符串使用，保留前导零和后缀。

**库存覆盖是否等于交付承诺？** 不等于。库存分析与指定日期的交付分析口径不同，必须按题目要求提供业务日期、需求和供应条件。样例是历史回放，不代表实时库存或真实交期。

**如何验收？** 安装后通过 MCP 检查对象、函数和 Skill，再使用源码中的 [v4 业务场景测试集](../bkn-eval/baselines/2026-10-30-business-scenarios-v4/README.md)核对 50 道题。答题 Agent 不读取参考答案。
