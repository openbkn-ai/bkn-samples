# 供应链安装与验收指南

## 在线安装

1. 登录 OpenBKN，进入首页的**一键体验**。
2. 刷新官方目录，选择**供应链**，确认版本后点击**安装**。
3. 等待数据准备、资源扫描、知识网络导入绑定、能力发布及安装验证完成。
4. 安装成功后打开知识网络，查看对象和关联数据。

安装服务会自动执行数据加载、导入和能力发布，不需要客户或伙伴手工建库、复制配置或运行脚本。

## 离线包导入

从 [Releases](https://github.com/openbkn-ai/bkn-samples/releases) 选择供应链版本，下载 `package.tar.gz`。在一键体验中点击**导入离线包**，上传后选择该版本安装。

离线包引用固定的数据镜像，并不包含镜像本身。目标集群必须能够拉取该镜像；不能联网时，请由管理员提前将镜像准备到环境中。

## 业务能力与 MCP 验收

接入外部 Agent，确认它通过 MCP 能发现知识网络、两个原生计算函数和两个 Skill（PMC 生产计划、采购跟进）。用 Cypher 查询产品 `382-000005` 的欠货及库存，再调用函数检查可做数量、齐套和缺料。函数与 Skill 必须实际调用成功，不能以安装成功代替业务验收。

原生函数实现位于 `tools/fn/`，安装 hooks 自动发布。调用者只提供声明的业务参数，不自行构造 `resolved_context`，不传凭据、服务地址或库存快照；不要用本地 CSV 计算替代 MCP 的实际结果。

## 业务场景 50 题评测

源码仓库中的 [v4 业务场景测试集](../bkn-eval/baselines/2026-10-30-business-scenarios-v4/README.md) 提供 50 道题和参考答案，题目与口径来自 [PRD](PRD.zh-CN.md)。独立外部 Agent 通过 MCP 答题，答题时不提供参考答案；每题跑一轮，完成后逐题核对业务值。

## 失败与重新安装

安装失败时查看失败详情，处理后重试同一安装记录。若提示原始 manifest 不匹配，请保留错误及版本信息，联系管理员处理，不要手工导入另一版本覆盖失败记录。

体验新版本前先卸载旧版本，等待清理完成后再安装。卸载会删除样例数据和用户修改；仅删除离线包缓存不会清理已安装资源。安装记录没有卸载入口或清理失败时，请联系管理员。

常见问题见 [FAQ](faq.md)。

## 存货类别与物料分类说明更新

`group_name`是存货类别，`group_type`是物料分类；字段名、映射和源数据值不变。
本次源码说明随新的样例制品发布并导入后才会生效，已发布版本及冻结验收记录保持原样。
`tools/import_kn.py`会复用已有同名受管网络，不会因重跑而覆盖这些说明。已有网络应由有权限的维护者先核对用户自定义，再显式更新这两个属性的说明；不要为此盲目重导入或卸载。
验证时读取已安装网络的属性定义，并执行[MF-01分类回归](../bkn-eval/README.md#分类字段与交期附加事实回归mf-01)。源码本地测试通过不代表已有网络或模型回答已修复。
