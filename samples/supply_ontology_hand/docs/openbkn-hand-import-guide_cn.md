# 供应链安装与验收指南

> 本维护版本0.1.16面向原始正式 OpenBKN0.2.0：使用 URL-only offline.v1 包及预先可用的固定数据镜像。后来含共享数据库补丁的020安装器使用另一种包协议，不能安装本包；请按实际服务能力选择版本。此处的离线导入不表示压缩包包含镜像。

## 在线安装

1. 登录 OpenBKN，进入首页的**一键体验**。
2. 刷新官方目录，选择**供应链**，确认版本后点击**安装**。
3. 等待数据准备、资源扫描、知识网络导入绑定、能力发布及安装验证完成。
4. 安装成功后打开知识网络，查看对象和关联数据。

安装服务会自动执行数据加载、导入和能力发布，不需要客户或伙伴手工建库、复制配置或运行脚本。

## 离线包导入

从 [Releases](https://github.com/openbkn-ai/bkn-samples/releases) 选择供应链版本，下载 `package.tar.gz`。在一键体验中点击**导入离线包**，上传后选择该版本安装。

离线包引用固定的数据镜像，并不包含镜像本身。目标集群必须能够拉取该镜像；不能联网时，请由管理员提前将镜像准备到环境中。

## 业务能力与 MCP 验收

接入外部 Agent，确认它通过 MCP 能发现知识网络、指标、原生 Function Toolbox 和 Skill。查询产品 `382-000005` 的订单及库存，并按明确的业务参数调用函数，检查齐套、缺料和交期分析。函数与 Skill 必须实际调用成功，不能以安装成功代替业务验收。

原生函数实现位于 `tools/fn/`，安装 hooks 自动发布。调用者只提供声明的业务参数，不自行构造 `resolved_context`，不传凭据、服务地址或库存快照；不要用本地 CSV 计算替代 MCP 的实际结果。

## 核心 50 题评测

源码仓库中的 [BKN-Eval](../bkn-eval/README.md) 提供问题集、参考答案和[体验评测指南](../bkn-eval/体验评测指南.md)。独立外部 Agent 通过 MCP 答题，答题时不提供参考答案；完成后核对结果字段、排序和业务值。核心 50 题验收应使用实际安装版本及其对应数据基线。

## 失败与重新安装

安装失败时查看失败详情，处理后重试同一安装记录。若提示原始 manifest 不匹配，请保留错误及版本信息，联系管理员处理，不要手工导入另一版本覆盖失败记录。

体验新版本前先卸载旧版本，等待清理完成后再安装。卸载会删除样例数据和用户修改；仅删除离线包缓存不会清理已安装资源。安装记录没有卸载入口或清理失败时，请联系管理员。

常见问题见 [FAQ](faq.md)。
