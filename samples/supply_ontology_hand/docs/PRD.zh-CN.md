# 农机与无人机供应链：订单交付、物料保障与采购跟进 PRD

## 业务目标与使用者

一家生产北斗导航驾驶仪、车载终端、农业无人机和智能探测系统的制造企业，需要让计划和采购人员直接用业务语言问清交付和物料问题。核心使用者有两类：

- **PMC 生产计划经理**：欠客户的货什么时候能补齐；新单能不能接、能接多少；工单排下去料够不够；预测要备多少料。
- **采购经理**：哪些料卡住了生产；哪些在途该催、找哪家供应商；哪些料没有在途必须马上下单、最早什么时候到。

成功标准：使用者提问时不需要说明计算规则，就能得到符合本文业务口径的结论，并看到依据的订单、库存、BOM 和采购记录。规则必须写在问题里才能答对、换个说法就答错，不算达标。

## 决策范围

纳入：成品与物料主数据、多层 BOM 与替代料、各仓实时库存、销售订单签约与发货、需求预测、MRP 计划订单、请购、采购订单与到货、生产工单。

不纳入：真实下单、发货、排产或关闭单据；运输时间；产能与工时排程；价格与成本核算；预测模型训练。所有结论只作建议，不承诺实际执行。

## 业务口径

以下是默认规则，使用者提问时不必重复。使用者明确提出别的条件时，以使用者为准。

1. **业务日期**：2026-08-25。“现在”“今天”“当前”都指这一天；数据快照日期为 2026-08-13。
2. **可用库存**：只计库存状态为“可用”的可用数量；“不良”库存不能投产、不能发货。默认统计全公司所有仓。“成品仓”指苏州、乌鲁木齐、哈尔滨三个成品仓；“苏州工厂生产七仓”指苏州半成品仓、苏州成品仓、苏州电子原料仓、苏州无人机原料仓、苏州装配原料仓、乌鲁木齐成品仓、哈尔滨成品仓。
3. **欠货**：销售订单签约数量减已发货数量大于 0 即为欠货；承诺交期早于业务日期的欠货为逾期。多张欠单按承诺交期先后、再按订单号补发。
4. **在途采购**：采购订单行未关闭、未终止，且订购数量减实收数量大于 0。交期不早于业务日期的按交期计入供给；交期早于业务日期的为逾期在途，交期已经失信，不算确定能到的供给，作为催货对象单列，只有使用者明确假设“能催回来”时才计入。
5. **新下单到货**：外购件按物料的标准采购提前期，从业务日期起算。
6. **生产可做数量**：先用成品库存，不够的部分按 BOM 逐层展开；每一层先扣该组件的可用量，只对净缺部分继续往下展开，最后无法再展开的物料缺口才是真正的缺料。多个需求共享同一个库存池，不能重复使用同一份库存。默认不用替代料，也不计新采购。
7. **生产计划与在途**：问“现在、用现有库存能做多少”时只看库存；问到某个日期前的投料或交货时，可用量为库存加上该日期前（含当天）按交期到货的在途；逾期在途按第 4 条处理。
8. **替代料**：使用者允许替代时，同一替代组每个位置只选一种料，不混用；按各自单耗计算，优先选能满足更多需求的料，同样多时用主料。
9. **可承诺量**：成品可用库存加上按现有库存还能生产的数量，先扣除该产品已签约的欠货，剩下的才是可以承诺给新单的数量。
10. **预测**：关闭状态不是“已关闭”的预测视为未关闭。预测满足排在已签约欠货之后。
11. **单据追溯**：采购订单行按来源请购行和物料对应请购单行；请购单行对应生成它的 MRP 计划订单；MRP 计划订单对应其根需求预测单。一张预测单可以包含多个产品。

## 业务场景

| 场景 | 使用者的问题 | 期望得到的结论 |
|---|---|---|
| S01 产品与物料 | 卖哪些产品、有多少供应商、某个料多久能买到 | 型号、产品线、供应商数、采购提前期 |
| S02 订单欠货 | 欠客户多少、拖了多久、哪些补不上 | 欠单、逾期天数、客户与销售员的欠货、现货与生产都补不上的产品 |
| S03 预测与备料 | 预测压力有多大、能撑多少 | 未关闭预测、预测与库存倍数、零库存产品、先保欠货后的可支撑量 |
| S04 BOM 与通用料 | 一个料影响哪些产品 | 一级物料、反查用途、通用料、缺料影响面 |
| S05 库存 | 能发多少、哪些不能用 | 成品仓库存、物料库存、不良库存 |
| S06 接单与承诺 | 新单能不能接、能接多少、卡在哪 | 可承诺量、工厂与全公司差异、卡料与齐料日期、在途对可做数量的影响 |
| S07 欠单补发与多单争用 | 先补谁、同时来单怎么办 | 补不上的订单、共享库存与在途下的缺料 |
| S08 采购跟进 | 今天该到什么、该催谁、该新下什么单 | 在途与逾期、今日及当月到货、重点供应商、采购员负责面、可催与需新下单的缺料 |
| S09 交期与分时供给 | 最早哪天能到、某个日期前料够不够 | 下单到货日、替代后的瓶颈料、按日期计入在途的可用量、催回逾期在途后的可做数量 |
| S10 计划执行与追溯 | 计划落地了没有、料为谁备的 | 未投放 MRP、未完工工单、开工前缺料、采购到预测的追溯 |

## 验收标准

1. 每种语言 50 题，覆盖上述 10 个场景：基础 12、中等 20、复杂 18。全部用 PMC 或采购经理的业务语言提问，题干不写计算规则。
2. 复杂题至少同时涉及两条业务口径，或需要跨三类以上单据推理。
3. 参考答案独立于被测能力计算，被测方看不到答案。
4. 每种语言跑一轮，目标准确率 100%。
