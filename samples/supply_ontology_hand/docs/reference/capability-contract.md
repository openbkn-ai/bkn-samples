# 能力与验收口径

这是一份技术参考，不是导入步骤。请先完成[导入指南](../openbkn-hand-import-guide_cn.md)，再按本页理解 Agent 的调用边界与验收范围。

## 能力边界

样例回答的是供应链的**事实、计算和判断**，不创建采购单、不承诺客户交期、不写回业务系统。

| 层级 | 用途 | 调用方 |
| --- | --- | --- |
| 对象与关系 | 供应链事实与追溯 | MCP 对象查询 |
| 指标 | 简单统计与汇总 | MCP 指标 |
| 原生函数 | BOM、库存、齐套、可售、交期与争用计算 | MCP Function Runtime |
| Skill | 组织 S1 齐套倒排、S2 可售、S3 新需求覆盖的多步判断 | OpenBKN Agent |

函数实现位于 `tools/fn/`，由步骤 6 注册到原生 Function Toolbox。三个 Skill 位于 `skills/`，也在步骤 6 注册。调用者只传业务参数；运行时自行受管读取知识网络，调用者不得传入 Token、服务地址、数据快照、会话 ID 或 `resolved_context`。

## 三个业务场景

| 场景 | 业务问题 | 输出边界 |
| --- | --- | --- |
| S1 齐套倒排 | 某预测或订单能否按目标日期齐套 | 缺料、到货与风险；不是采购承诺 |
| S2 可售 | 当前最多可销售或可生产多少 | 可售数量；不是交期承诺 |
| S3 新需求覆盖 | 多个新需求争用库存后能否承接 | 顺序扣减后的缺口与风险；不是订单写回 |

## 通过标准

1. 样例数据、知识网络、目录扫描和资源绑定均完成；
2. 指标、原生函数和三个 Skill 已注册，且第三方 Agent 能经 MCP 抽样调用；
3. 核心 50 题只以 `bkn-eval/datasets/` 为准，按[体验评测指南](../../bkn-eval/体验评测指南.md)执行；
4. 结论必须带业务依据；超出数据或能力边界时应明确说明，不能臆造结果。

## 已知限制

- 当前版本不包含行动执行、监控任务、外置函数服务或离线 CSV 演示路径。
- 这不是生产全量模型；它用于验证知识网络、MCP 与业务能力的完整导入链路。
