# 指标查询口径与时间分析（0.1.5 候选）

本版本保留原有快照统计，新增一个独立时间指标。0.1.5 本地候选已通过离线导入和安装；扩展验收尚未全部通过，尤其月环比比较窗口仍有运行环境差异，不能据此宣布支持已验证。

## 能力矩阵

| 指标 | 业务口径 / 时间属性 | 即时值 | 趋势 / 同环比 | 普通分组占比 |
| --- | --- | --- | --- | --- |
| 产品总数 | 全量产品主数据，无时间语义 | 支持 | 不支持 | 无配置分组 |
| 物料总数 | 全量物料主数据，无时间语义 | 支持 | 不支持 | materialattr / group_name |
| 供应商总数 | 全量供应商主数据，无时间语义 | 支持 | 不支持 | purchaserid_name |
| 销售订单数 | 全量订单记录，不代表某期间新增 | 支持 | 不支持 | product_code / order_status |
| 仓库数 | 当前库存出现的仓库去重，不代表仓库历史 | 支持 | 不支持 | stock_status；去重分组会重叠，不把占比解释为互斥份额 |
| 库存可用量 | 当前库存快照；入库日不是库存快照时间 | 支持 | 不支持 | material_code / warehouse / stock_status |
| 预测需求量合计 | 当前预测记录汇总；截止日不是预测创建时间 | 支持 | 不支持 | material_number / closestatus_title |
| 未关闭预测单数 | 当前状态且显式排除已关闭 | 支持 | 不支持 | material_number / closestatus_title；保留同一未关闭过滤 |
| 签约数量合计 | 全部订单当前签约数量 | 支持 | 不支持 | product_code / order_status |
| 发货数量合计 | 全部订单当前累计发货量；不能据此推导每次发货事件 | 支持 | 不支持 | product_code / order_status |
| 按签约日期的签约数量 | 签约事件流量，salesorder.signing_date 映射为 date | 支持；期间需显式选择 | 支持，使用固定历史期间 | product_code / order_status；也支持按时间分桶占比 |

机器可核验的矩阵为 [metrics-capabilities.json](metrics-capabilities.json)。此文件是样例文档/验收契约，不是平台新接口字段。

无时间语义的指标默认即时请求为 `{"time":{"instant":true}}`，不附带 start/end/step。普通分组占比也使用即时聚合，并提供 analysis_dimensions 和 `metrics.type=proportion`。趋势、同环比与按时间分桶占比需要有效时间维度、明确范围及步长；不支持的模式应在使用说明中明确，平台请求行为属于运行环境边界。用户明确要求期间过滤时必须保留范围并由后端校验，不得静默忽略。

“未关闭预测单数”定义态 condition 的既有平台限制仍需注意：空请求可能返回 137，不能算通过。查询必须携带 `closestatus_title != 已关闭`，得到 90；需求量使用相同过滤为 56340。

## 固定历史窗口示例

时间指标的 `default_range_policy=none`。冻结样例的数据不会随当前日期滚动，最近 24 小时可能为空，因此趋势和同环比演示必须显式选择历史窗口。样例未新增或修改任何业务 CSV，核心 50 题及数据基线不变。

[metrics-analysis-examples.json](metrics-analysis-examples.json)提供完整请求和独立 CSV 预期值，业务时区为 Asia/Shanghai。请求毫秒时间戳对应该时区的月初/月末；其他时区部署须明确转换并重新核验，不能照抄为 UTC 边界。期间即时值采用 signing_date 的显式 `>=` 和 `<` 条件，保留完整业务月。真实验收核对平台日期解析、桶标签和边界，发现偏移先修时间契约，不用随机线上结果重写预期值。

- 月趋势：2026-03-01 至 2026-06-30，步长 month。签约数量依次为 6083、5319、4565、4429，总计 20396。
- 显式期间即时值：2026 年 4 月签约数量为 5319。
- 月环比增长量：4—6 月与前一个月比较，分别为 -764、-754、-136。比较期 3 月数据也包含在冻结 CSV 中。
- 普通物料属性占比：分母为全部 3497 种物料；外购 3149、自制 233、委外 114、虚拟 1。接口比例单位为百分比，四组共 100%。
- 4 月订单状态时间占比：分母为该月签约数量 5319，已确认 5310、执行中 9；同一时间桶内两组比例合计 100%。它表示当前订单状态分组的签约流量，不表示当时历史状态。

8081 的部署提交 628dd24 中，指标即时期间层按左闭右开构造 range，而 MariaDB 连接器将 range 转为闭区间；直接用月末最后一毫秒可能把下个月月初计入。示例的显式日期比较避免这个差异。月环比仍出现比较窗口截断及桶对齐差异：正确业务月窗口的原始返回为 null/-754/-88，独立 CSV 答案应为 -764/-754/-136。该案例继续作为失败门禁，不把返回值写入金标，也不通过本次 sample 修改平台。

分组验收必须取齐全部组并核对分母。按产品或仓库分组时，平台可能默认限制返回组数；截断结果不能作为完整占比验收。

使用安装后的真实指标执行扩展验收：

```bash
python tools/power_layer.py verify --kn-id supply_ontology_hand \
  --query-file tools/assets/metrics-analysis-examples.json
```

验证脚本逐组逐桶检查值、月份、增长量及比例；数字毫秒或带时区 ISO 时间戳按查询文件声明的 business_timezone 解释月份，无声明时沿用 UTC。运行环境须能加载声明的 IANA 时区；缺失时不应将月份校验算作通过。计数偏差 90→91 不再因 2% 容差被放过。此扩展验收独立于核心 50 题。

## 安装与发布边界

`create` 遇到同名指标会跳过，不更新已安装定义。按 [开发指南](../../../../docs/SAMPLE_DEVELOPMENT_GUIDE.zh-CN.md)构建新版本并在干净测试安装中验收；旧版本保持可复现。候选包真实导入、原生指标查询及核心 50 题全部通过前，不关闭 #23，也不宣称新版达到 100%。
