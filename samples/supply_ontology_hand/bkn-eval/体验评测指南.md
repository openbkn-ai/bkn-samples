# 供应链 BKN-Eval：核心 50 题对比

本评测比较两条独立路径在同一供应链快照上的业务结论：A 基于 OpenBKN 知识网络与 MCP；B 直接只读数据库；C 在两份回答冻结后使用金标独立评判。评测只读，不采购、不承诺、不写回。

## 固定边界

- 知识网络：`supply_ontology_hand`。
- 数据快照：2026-08-13；业务日期：2026-08-25。
- 题集：[问题集](datasets/sample-question-set-v1.yaml)；A、B 可读。
- 金标：[答案集](datasets/sample-answer-set-v1.yaml)；仅 C 可读。
- 范围：M、F、R、S 四类核心 50 题。

## 运行前检查

1. 已完成样例导入手册的步骤 1～6；Agent 有 Context Loader MCP 只读权限。
2. A 能发现已发布的供应链函数工具箱与 Skill，并在受管 Interaction 内调用“标准交期”（`606-000989`，14 天）和“BOM清单”（`382-000005`）。
3. B 仅持有同一快照数据库的只读 `.env`；不得调用 OpenBKN、函数、Skill 或 Action。
4. 记录 sample、题集、答案集、函数和模型版本；不要记录密码、Token 或服务地址。

## A：基于 BKN

将问题集交给 A。A 只能经 MCP 读取知识网络：事实走对象查询，简单汇总走指标，BOM、齐套、可售、交期与争用走已发布函数。每题单独创建并结束 Interaction；函数只传业务参数，不传 Token、服务地址、快照、会话 ID 或 `resolved_context`。

A 输出每题原始回答、开始/结束时间、运行状态和可回放的 Interaction 证据。函数不可用时如实标记失败，不得用本地 CSV、CLI、SQL 或自建计算顶替线上结果。

## B：直连数据库

将同一问题集和只读 `.env` 交给 B。B 可用只读 SQL 或临时计算，但不得读取金标、样例源码、历史报告，或调用任何 OpenBKN 能力。B 输出每题原始回答、开始/结束时间、运行状态和计算口径。

## C：独立评判

确认 A、B 的 50 题原始回答均已保存后冻结，再将答案集交给 C。C 对每题输出“通过”“答案不一致”或“运行条件未声明”，并单列可核验的硬失败：数据错误、违背业务函数/规则、遗漏必要澄清、越权承诺或证据不可回放。

最终报告按 M/F/R/S 汇总 A、B 的通过数、运行条件、时长和差异原因；对 A 定位到数据、对象关系、函数口径、Skill 编排、治理或表达。不要把单次结果泛化为产品结论；版本变化后新建报告，不覆盖历史报告。
