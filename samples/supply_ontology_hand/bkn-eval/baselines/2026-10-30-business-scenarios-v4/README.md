# v4 业务场景测试集（评审草案）

依据 [供应链 PRD](../../../docs/PRD.zh-CN.md) 的业务场景和业务口径编写，共 50 题：基础 12、中等 20、复杂 18；PMC 视角 33 题、采购视角 17 题。题目以业务语言提问，不在题干里写计算规则。

- `question-set-v4.yaml`：题目、场景、难度、角色与输出要求。被测智能体只能看到这一份。
- `answer-set-v4.yaml`：机器可读的期望值。被测智能体不得读取。
- `oracle.py`：只读 `data/` 下交付 CSV，用 Decimal 独立计算全部答案并生成上面两份文件；不导入或调用样例函数，也不读取历史答案。

```sh
python3 samples/supply_ontology_hand/bkn-eval/baselines/2026-10-30-business-scenarios-v4/oracle.py
```

## 在途数据现状

未关闭的在途采购行共 517 行，其中 483 行已逾期；交期不早于业务日期的只有 34 行，这些到货都不会改变任何产品的可做数量。逾期在途如果能催回来，U00-000080 和 P61 系列的可做数量会明显增加。题目据此考察“按期在途”与“逾期可催”的区分，不额外编造在途数据。

## 与 v3 的差异

v3 题干写明“先扣成品再逐层扣组件、全仓、不计 PO”等规则，直连数据库也能照做；v4 去掉这些提示，并加入需要跨单据推理的问题，例如先保欠货再算可承诺量、区分按期在途与逾期可催、按交期补发欠单、采购到预测的单据追溯。
