# 供应链 BKN-Eval

这是供应链本体样例的对照评测包。它用同一份供应链样例数据、同一组核心业务问题，比较两种智能体答题路径：

- **A：基于 OpenBKN**——通过供应链知识网络查询事实，并调用已发布的供应链函数。
- **B：直连数据库**——只读查询同一份数据库快照，自行理解并计算业务口径。

目的不是比较模型“会不会写 SQL”，而是观察知识网络、统一业务口径和已发布函数，是否能让智能体在齐套、交期承诺、可售能力和 BOM 分析等问题上给出更稳定、可追溯的结论。

## 使用边界

评测仅读取样例数据，不创建采购订单、不写回业务系统。`.env.example` 仅提供 B 路径所需的连接变量名；实际 `.env` 包含凭据，不应提交、分享或写入报告。

## 分类字段与交期附加事实回归（MF-01）

[问题](datasets/material-field-questions-v1.yaml)与[参考答案](datasets/material-field-answers-v1.yaml)
是独立于冻结核心50题的单项回归。被测Agent只读取问题与已安装的BKN/MCP信息，不能读取答案、CSV或本地函数源码。
交期和两项分类必须全部正确；把物料分类放到存货类别下时整体失败，不能只按“1天”判通过。
本地测试只验证元数据、导入载荷和CSV金标一致，不是模型回答或现场MCP验收成绩；实际回答需单独保留并评判。
