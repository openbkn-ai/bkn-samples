# 供应链 BKN-Eval

这是供应链本体样例的对照评测包。它用同一份供应链样例数据、同一组核心业务问题，比较两种智能体答题路径：

- **A：基于 OpenBKN**——通过供应链知识网络查询事实，并调用已发布的供应链函数。
- **B：直连数据库**——只读查询同一份数据库快照，自行理解并计算业务口径。

目的不是比较模型“会不会写 SQL”，而是观察知识网络、统一业务口径和已发布函数，是否能让智能体在齐套、交期承诺、可售能力和 BOM 分析等问题上给出更稳定、可追溯的结论。

## 最近一次正式评测

| 项目 | 结果 |
| --- | --- |
| Agent 运行环境 | POC / DeepSeek Harness |
| 大模型 | DeepSeek V4 Flash |
| 数据快照 / 业务日期 | 2026-08-13 / 2026-08-25 |
| 题目范围 | 核心 50 题：主数据、BOM/齐套/供应、BOM 关系、交期/承诺 |
| A：基于 BKN | **50 / 50，100%**；总时长约 11 分钟。 |
| B：直连数据库 | **26 / 50，52%**；总时长约 16 分钟。 |

| 题型 | A：基于 BKN | B：直连数据库 |
| --- | ---: | ---: |
| M 主数据（15 题） | 15 / 15 | 15 / 15 |
| F 齐套/供应（15 题） | 15 / 15 | 2 / 15 |
| R BOM 关系（9 题） | 9 / 9 | 6 / 9 |
| S 交期/承诺（11 题） | 11 / 11 | 3 / 11 |

本轮差异集中在业务口径：生产可用仓范围、净需求与在途口径、BOM 主料去重、替代料可产能力，以及预测单与倒排树的读取。直连数据库路径在 S-10“供货能力是否满足”给出与金标相反的结论；A 路径通过已发布函数使用统一口径并保留可回放证据。

## 使用边界

评测仅读取样例数据，不创建采购订单、不写回业务系统。`.env.example` 仅提供 B 路径所需的连接变量名；实际 `.env` 包含凭据，不应提交、分享或写入报告。
