# Supply chain · candidate version 0.1.2

## Contents

- Adds the read-only `demand-fulfillment-risk-summary` Skill for summarizing fulfillment gaps and date risks.
- Keeps the existing database, knowledge network, functions and installation profile unchanged.

## Limitations

- Anonymized historical data must not be used to make real delivery commitments.
- The Skill does not create purchase orders, monitoring records or other business data.
- Installation requires an administrator and a working platform; questions also require a configured model.
