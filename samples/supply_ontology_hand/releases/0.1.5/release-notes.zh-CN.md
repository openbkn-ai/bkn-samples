## 完整自然月验收修正

通过签约日期指标查询连续完整业务月，再由第三方 Agent 计算相邻差值。新增可经 MCP 发现的自然月分析 Skill，明确时区、左闭右开边界、比较基线、过滤及缺失值规则。验收客户端先检查每个月的真实数量，再检查派生增长量。此前 SDK sameperiod 请求保留为可选独立诊断，不证明 Agent 有错，也不作为这条业务路径的发布阻断项；此前过度的平台归因撤回。CSV 和金标不变。本次修订必须重新安装精确包并独立 MCP 补验，不移用此前核心成绩；10月3日函数审查中的其他问题不由本次自然月修正解决。

## 确定性业务规则修订

修正主料分类、默认全仓、成品及逐层组件先抵扣、请求共享池、不同替代单耗和确定候选选择。数量分析不计在途；日期覆盖只计业务日期之后且不晚于需要日的未关闭净在途，并返回按期覆盖与缺口。同步修订 Skill 和新 50 题/答案基线，答案由独立 CSV 重算，不沿用旧成绩。S-01/S-05/S-08 使用明确资源池给确定判定。完整制造排程仍需独立场景验收。本精确候选的 MCP 验收结果随评测基线保存。
