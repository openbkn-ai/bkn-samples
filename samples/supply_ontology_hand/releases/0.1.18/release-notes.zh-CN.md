# 0.1.18：移除 Skills 实体类

仅从中文供应链模型移除 `id=skills`、`name=Skills` 的实体类。基于 0.1.17，实体由 12 个减为 11 个，14 条关系及业务数据不变；全部业务实体均在资源映射中。两个 Skill 的注册、发布、挂载及验收保持不变。英文供应链和其他样例不变。

更新源码不会删除已安装模型中的实体。现有安装继续使用原版本；更换版本须按标准卸载、安装流程进行，先保留需要的数据和用户修改，卸载会清理样例数据及归属资源。本版本不提供原地迁移，也不自动清理线上对象。

本地模型、资源映射与 Skill 契约检查通过后仍须对固定候选包做全新安装验收；本说明不代表已发布或已在 8081 安装。

安装、资源绑定、函数/Skill 注册和验收脚本还接入可选的统一子进程诊断：记录具体动作、退出码和失败原因；原业务执行与回执协议不变。旧安装器不具备诊断模块时继续使用原执行方式。此内容变化后的候选必须重新构建，前一份 0.1.18 候选的模型验证不代表新包完整安装已通过。
