# 0.1.23：排产计划记录的齐套结论与甘特检查一致

基于 0.1.22。业务数据、对象、关系和行动都不变。

**齐套结论统一**：建立或调整齐套排产计划时记录的齐套结论，现在与排程甘特上“齐套检查”的结论完全一致。两处用同一套计算：先保已签约欠货，再按已确认、已排和开工先后，与知识网络里其他有效计划一起分配库存和在途；已开工的产品物料已领用，不再占料；缺料说明里的计划开工就是计划自己的开工日。此前在甘特上通过检查的在制计划，调整后可能被记成缺料，开工日也被写成业务日期，这个问题已修正。安装时带的排产历史也按同一套计算生成。

现有安装继续使用原版本；更换版本须按标准卸载、安装流程进行，卸载会清理样例数据及归属资源。本版本不提供原地迁移。
