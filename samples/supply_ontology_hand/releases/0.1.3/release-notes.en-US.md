# Supply chain · candidate version 0.1.3

## Contents

- Installs the existing supply-chain metrics through the standard metric API.
- Binds metrics to knowledge-network object logic properties.
- Requires metric queries and bindings to pass verification before installation succeeds.
- Retains the database, knowledge-network structure, 14 functions and four Skills from 0.1.2.

## Limitations

- Anonymized historical data must not be used to make real delivery commitments.
- Requires an administrator and a working platform; agent questions require a configured model.
- Existing installations are not upgraded in place. Use a fresh test installation to evaluate this version.
