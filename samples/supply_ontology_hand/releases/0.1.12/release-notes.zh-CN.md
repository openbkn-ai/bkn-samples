# 0.1.12：明确物料分类字段

明确物料 `group_name`（存货类别）与 `group_type`（物料分类）的说明，防止查询标准交期时混用两个分类。字段名、显示名称、映射、数据和交期计算不因本次修复改变。源码另附独立 MF-01 验收题；评测题与金标不进入安装包。

本包来自包含 #204 的供应链主线，使用产品共享 MariaDB，要求 OpenBKN >=0.2.1 <0.3.0。与此前已安装版本的其他差异应结合完整包验收，不能只凭字段单测认定兼容。缺料规则依赖另行配置的事件投影及受信 App Spec 映射；本次分类回归不声明 Workshop 联调通过。

新版本不会覆盖现有网络。已有网络若含自定义，请先保留并审阅；维护者可显式更新这两个说明并读回验证。需要更换整个样例包时，按产品既有卸载、安装流程操作；卸载会清理该样例数据和归属资源。不要把重试安装视为元数据更新。实际验收结果单独随发布证据记录，本说明不承诺模型所有回答均正确。

同时将尚未正式发布的补货草稿 Action ID 缩短至 40 字符以内，同步定义、绑定、结果引用和验证。该样例标识同时兼容已有测试部署和当前主线，不改变平台 ID 规则或补货业务逻辑。

修正固定包安装时函数源码 ZIP 不接受归一化为 Unix epoch 的文件时间戳的问题：仅在打包时将 ZIP 时间戳钳制至其支持范围，源码内容与计算行为不变。
