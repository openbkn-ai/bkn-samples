# 业务规则：产品可售能力（S2）

本文件是 S2 包内的业务边界说明。权威计算由已发布的合计可售函数执行，Skill 不另写公式。

1. 产成品库存 `fg_qty` = 三个成品仓 `available_inventory_qty` 合计（苏州/乌鲁木齐/哈尔滨成品仓）
2. 单料最大可产 = `FLOOR(生产可用 / 单耗)`；单耗 ≤ 0 → 0
3. 启用替代：替代组可产 = 组内成员 **MAX**；该位置可产 = `MAX(主料, 替代组)`
4. 理论可产 = 叶子主料（或替代后入选料）可产的 **MIN**；不加成品、不加在途
5. 合计可售 = `fg_qty + theoretical_build_qty`
6. 预留库存只展示、P0 不扣
7. 在途 PO 不进入合计可售
8. 未确认替代开关 → 不能算
