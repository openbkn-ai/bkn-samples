# 业务规则：产品可售能力（020 修正版）

1. 成品为三个成品仓的可用量，生产为既有七仓；必须回显实际范围。
2. 主料是 alt_priority=0，替代料是 alt_priority>0。替代组内的主料不能排除。
3. 按 BOM 位置逐层抵扣半成品，只对未覆盖部分展开下层。相同物料使用请求内共享库存池，不能重复抵扣。
4. 理论可产不含成品、不含 PO；以整数数量试算可行性，保留 N 与 N+1 边界。单耗必须有限且大于零。
5. 允许替代时，每个位置只选一项，按候选各自单耗计算覆盖，同覆盖优先主料，再按原顺序；不是混合替代或通用最优排产求解器。
6. 合计可售 = 三仓成品 + 七仓新增可产；预留已反映在可用量中，不再次扣除。
7. 数量能力不是交期承诺；不能用库存量直接推断采购、制造或发运必然按期。
8. 替代开关必须明确，未确认时先澄清。
