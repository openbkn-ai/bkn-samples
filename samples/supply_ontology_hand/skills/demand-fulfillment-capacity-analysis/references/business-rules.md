# 业务规则：产品可售能力（S2）

1. 默认全仓；显式成品/生产范围分别遵守。
2. 成品可用量按可用字段汇总；不重复扣预留。
3. 理论可产是排除成品和在途后，组件先抵扣、净缺再展开下层的最大可行制造量；不能仅对叶子 `floor(库存/单耗)` 取最小值。
4. 每次可行性计算使用独立库存池；一次计算内所有分支共享库存。相同替代料不能重复占用，资格和用量均按各 BOM 位置。
5. 合计可售 = 成品可用 + 理论可产。该数值表示库存覆盖，不表示现货全部可立即发运，也不证明日期承诺。
6. 替代开关未确认、BOM/库存未完整取得或业务口径不支持时不能给确定值。

计算由发布函数执行，Skill 用本契约检查适用范围，不本地另算金标。

## 确定分配策略

同一 BOM 位置只选择一个当前候选，不混合候选凑数；候选按能覆盖父件需求最多者选择，同值时主料优先，再按 BOM 原始行顺序稳定决胜。共享库存按物料池扣减。该策略支持量是确定的评测口径，不声称替代组合的全局最优；题目若要求全局最优，必须建立单独问题契约和答案集。

主料/替代候选须组合检查 `alt_method`、`alt_group_no` 与 `alt_priority`：普通主料优先级为 0；替代方法且有组号、优先级 0 是组内主料，正整数才是替代候选。不得把“替代”方法的全部行排除，也不得只凭优先级推断；字段矛盾或未知方法须明确失败。
