# 报告规范：新需求覆盖（S3）

```markdown
# 新需求覆盖分析报告

## 报告信息
- 知识网络 / 替代料开关 / 仓名单 / 扣减顺序

## 无数量时
- 产品 BOM 共用清单：shared_codes / shared_count
- 明确写：这不是争用，也不是满足结论

## 有数量时
- 总体：需求数、不满足产品数、共享缺料数
- 分产品：需求量、争用扣减后的满足状态
- 默认回显：每单缺料清单与扣减顺序；篇幅不足时写“展示前 N 项，共 X 项”，不得把部分清单表述为全部
- 需要逐料诊断时：明确以 `report_grain=full` 取得毛需求、已分配、短缺、是否共享及争用扣减后剩余

## 建议
- 补货建议仅使用 `recommended_replenishment_qty`（当前需求快照净缺）；MOQ、安全库存或其他需求未给出时，不擅自加量
- 调整优先级或数量后重跑
- 不要自动下 PO
```
