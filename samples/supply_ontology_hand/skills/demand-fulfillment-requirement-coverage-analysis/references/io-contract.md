# 输入输出契约：新需求覆盖

输入为唯一产品编码对象数组，数量全部明确或全部缺失。争用模式确认替代、扣减顺序、仓范围（缺省 `all`）；当前争用函数仅计可用库存，不计在途。日期供应覆盖另调用已发布供应函数，参数须从 MCP 发现，不自行猜测。

结构模式调用 **产品 BOM 共用清单**，输出 `shared_codes`、`shared_count`，不输出满足或短缺。

争用模式调用 **共用料与多需求争用**，回显实际 `deduction_order`、`warehouse_filter`、逐单 `allocations`、满足状态及 `shortages`。完整分配证据使用 `report_grain=full`（实际支持时），包括成品抵扣、净制造、逐层已分配/净缺和剩余池。摘要足够回答一般承接题，缺少全量明细不等于失败；需要全量时完整读取分页。

字段以真实函数出参为准，不伪造固定 JSON 数值。函数不支持条件或返回不完整时明确无法确认，不使用 CSV、数据库直连或答案集补齐。
