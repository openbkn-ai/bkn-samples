# 业务规则：新需求覆盖（S3）

本文件定义 S3 的结构交集与多需求争用边界。权威计算由已发布函数执行：数量全部缺失时使用产品 BOM 共用清单，数量完整时使用共用料与多需求争用；Skill 不另写公式。

1. 产品数 < 2 → 不能算（请改用单产品函数/S2）
2. 数量全部缺失 → 只输出产品 BOM 共用清单（全部传入产品的子件交集）；禁止满足结论
3. 数量部分缺失 → 先补齐数量或改为纯结构分析；不得猜测数量
4. 数量全部明确 → 每单按自身 BOM 展开，物料共享池按确定的需求顺序扣减。
5. 共享池 = 生产可用库存 + 未关闭 PO 未清；PR 不进供给。
6. 替代料未确认 → 不能算；启用时按函数的替代覆盖规则执行。
7. 不要把结构共用清单的 `shared_count` 当成争用缺口
8. 扣减顺序必须在调用前确定并回显；同优先级保持用户传入顺序

## 020 需求口径

- 客户供货调用齐套/争用函数时传 `demand_mode=fulfillment`，先用三仓成品，再展开剩余制造需求；明确必须新生产时传 `production`（保留默认）。
- 半成品先抵扣，剩余量才展开下层；成品、半成品、原料及未关闭 PO 未收数量按请求内共享池依序消耗，不得复用。
- PO 数量覆盖不等于按期到货；PR/MRP 不加入供给。日期题须检查到货、制造和题设交付条件。
- 缺料种数按料号去重。
