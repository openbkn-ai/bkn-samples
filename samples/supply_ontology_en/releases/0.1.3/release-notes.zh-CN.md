# 0.1.3

- 每个原生函数以单个可读的 Python 源文件发布，只包含该函数实际用到的计算代码，不再把全部模块压缩成 base64 归档打包进每个函数。函数名称、参数和计算结果不变。
- 函数通过沙箱预装的 `bkn_osdk` 读取知识网络。它走公共 BKN 接口，网关地址和凭据由运行时提供，代码中不写地址；在关闭 Trace 采集的 OpenBKN 0.2.0 部署上同样能读取数据。
- 不再发布 Agent Skill。倒排函数的业务规则说明移到 `docs/backward-plan-business-rules.md`；知识网络中的「技能」对象类不受影响。
- 数据、知识网络模型和指标不变。旧安装请先卸载，再安装此版本；不提供原地迁移。
