# 0.1.22：自带应用的业务文案，导出文件可直接复用

基于 0.1.21。业务数据、对象、关系、函数和行动都不变。

**“Kit Scheduling”应用**：
- 需求视角的计划条只显示齐套状态，不再显示产线编码；排到哪条产线见该行的状态说明，产线编码在悬浮卡里。
- 待排区卡片增加预测数量。
- “计划资源”改称“计划产线”。英文应用的规则名改为业务用语 Kit check、Line can build（调用的函数不变）。

**导出即可复用**：安装器直接接受应用工坊导出的应用文件。文件里原环境的应用 ID 不再使用；规则函数原有的工具箱和工具 ID 一律按工具箱名和函数名在本次安装中重新查找、替换。样例文档补充了在客户环境复用应用的步骤：怎么导出、先准备哪些对象和函数、怎么导入、怎么改成客户自己的数据。

现有安装继续使用原版本；更换版本须按标准卸载、安装流程进行，卸载会清理样例数据及归属资源。本版本不提供原地迁移。
