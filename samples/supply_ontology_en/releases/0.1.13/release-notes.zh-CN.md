# 0.1.13：移除未绑定数据源的 Skills 实体

0.1.12 候选包在完整安装验收中发现：`skills` / `Skills` 实体没有已发布数据源，查询返回 HTTP 503。本版仅移除这一实体，保留 11 个业务实体及原有 14 条关系；数据、函数、Skill 文件与其注册流程不变。这是中文 #217 修正的英文对应处理。

保留 0.1.12 引入的可选安装诊断。失败草稿及其摘要作为证据保留，不正式发布、不覆盖包；本版必须重新完成安装、重试和卸载重装验收。

已有安装在保留必要数据及用户修改后，使用标准卸载/安装流程切换版本。卸载会清理样例拥有的数据与资源，不提供原地迁移。
