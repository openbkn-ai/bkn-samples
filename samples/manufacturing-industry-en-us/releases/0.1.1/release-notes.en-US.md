# Manufacturing Operations (EN) · 0.1.1

Offline patch release that makes the BKN model compatible with OpenBKN 0.2.1 identifier limits.

- Shortens the knowledge-network display name and all 71 relation IDs to 40 characters or fewer.
- Replaces technical relation display names with concise English business labels; maps and CSV foreign keys are unchanged.
- Preserves sanitized BKN CLI diagnostics if an installation command fails.

## Limitations

The data is fictional. This candidate is intentionally not registered in the online catalog. It requires its matching fixed data image to be preloaded in the target environment.
