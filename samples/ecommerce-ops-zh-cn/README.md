# 电商经营决策（中文）

基于完整电商业务数据快照，分析订单收款、退款、库存与缺货预占、采购补货、分批发货、物流、营销优惠券及售后。

版本0.1.0。实际发布状态和安装验收证据见对应Release的固定制品元数据。

通过Studio“一键体验”在线安装，或导入同一版本的 `package.tar.gz` 离线安装。依赖产品提供的共享样例MariaDB、Vega、原生函数、OSDK沙箱、指标及事件接口；问答另需配置模型。外部API和知识库保留配置，相关服务须由目标环境提供。

数据装载使用安装器注入的专属账号，不连接原业务数据库，不修改源表，不基于视图建立实体。安装重新绑定资源、工具及Skill，指标历史版本随原生BKN资产恢复。7个事件托管对象由事件接口生成，避免重复创建。

事件安装后基于包内数据执行检查，金额与时间口径见指标及函数说明。历史快照按当前时间检测可能产生存量异常；验收使用固定时点比对候选主体及证据。原人工处理历史不作为样例初始数据恢复。新4类事件保持按需执行，未默认部署常驻程序。

数据文件及装载校验摘要见 `dataset.lock`。数据发布授权范围与最终验收结论在正式发布前冻结；候选包不等于验收通过。

本轮按要求暂缓索引构建及其验收，标准安装不自动提交索引任务，索引构建结果不作为本轮安装通过条件。包内保留主键、字段索引和模型名称配置，供后续阶段使用；不宣称向量检索效果已经验收。
