# 电商经营决策（中文）0.1.0

首版标准样例：订单、收款、库存预占、采购入库、分批发货、营销优惠券、售后、购物车及经营异常分析。

提供40个对象类、63个关系类、15个行动类、10个值类型、67个指标、39个Python/Cypher函数、10个OpenAPI工具及3个业务Skill。包含7类事件规则，支付失败等待15分钟、物流停滞48小时、退货收货后处理等待24小时。

在线和离线使用同一个固定包；数据装入样例专属数据库。既有外部API与知识库配置作为环境前提保留，不随包部署外部服务。自然语言问答需要目标环境配置模型。

新4类事件按需检测，未增加宿主机常驻巡检服务。历史异常按包内数据重新检测，原网络的人工处理历史不迁移。实际安装验收结果由对应固定制品的verification.json记录。
