# 世界杯场景评测

本评测集面向中文世界杯本体，使用 `dataset.lock` 固定的 Fjelstul 历史数据：27 张 CSV 表、81,200 行，男足赛事截至 2022 年，女足赛事截至 2019 年。各明细表的覆盖范围不同。

## 问题分类

| 类别 | 题数 | 主要考察内容 |
| --- | ---: | --- |
| 基础查询统计 | 10 | 届数、比赛数、球队和球员标记、比分、事件计数及快照覆盖 |
| 多表关联 | 12 | 奖项、名单、教练、裁判、积分榜、主办方及比赛事件 |
| 排名和跨届对比 | 14 | 并列排名、球队和足联表现、进球及得牌比较 |
| 综合分析 | 14 | 比赛历程、进球构成、名单使用、点球大战及数据核对 |
| 合计 | 50 | 从基础事实查询到关联、排名及综合分析 |

问题位于 [question-set-v1.yaml](datasets/question-set-v1.yaml)，参考答案位于 [answer-set-v1.yaml](gold/answer-set-v1.yaml)。每题明确 `output_fields` 和 `row_order`，保持列名和排序可核对。人员、球队、奖项等文本保留数据源的英文拼写与重音符号；题面使用中文，业务标识符及源记录不翻译或改名。

## 业务口径

- 比赛按 `matches` 或不同 `match_id` 计数。`team_appearances` 一条记录对应一支球队的一场比赛，同场有两条球队记录。
- 球员进球排除 `own_goal=1`；球队记账进球包含该队受益的乌龙球，按 `goals.team_id` 归属。`player_team_id` 表示进球者所属球队。
- 比赛内点球属于 `goals.penalty`；点球大战罚球属于 `penalty_kicks`，不加入比赛进球或比分。
- 得牌标记可能重叠，各标记分别统计。胜负平使用源记录标记，不自行改写点球大战后的判定。
- 竞赛排名使用同分同名次、后续跳号的规则；按排名边界返回全部并列者。恰好取 10 行的题目另行规定打破并列的顺序。
- R-11 包含全部洲际足联，未参赛者胜场为 0。1950 年赛事按实际决胜循环赛记录核对，不虚构淘汰制决赛。
- WC-1999 球员上场记录数为快照覆盖问题；零行不表示现实中没有球员参赛。

## 通过 MCP 评测

网络 ID：`worldcup_vega_catalog_bkn`。

只向独立的外部 Agent 提供问题集和该网络的 MCP 访问。Agent 自行查看已发布模型、用 `query_object_instance` 分页读取对象数据，再完成关联、排名与计算。可以使用普通 Python 或标准沙箱计算能力；不调用运行时 SQL、Vega 内部查询接口或平台内部 `bkn-agent`。

中文模型的 `matches` 和 `team_appearances` 各有 10 个 CSV 展示字段未声明。评测不假设这些字段可以直接查询：相关题目明确了补充关联对象，Agent 应从球队、裁判场次、进球、教练场次等已发布对象获取名称或赛事阶段。数据库中的数值返回值可能是文本，比较容量、排序行键及计算前须转换为数值。

评测期间不向 Agent 提供 `gold/`、CSV 文件、参考查询或其他评测答案。完成后逐题比较必需字段、实际业务值和规定排序，舍入比率容差为 `0.0005`。必须读取完整数据页，不能将第一页或截断结果当作全部记录。验收目标为 50/50；未运行或不能取得充分数据的题目不能标为通过。

## 重算参考答案

从仓库根目录执行，Python 需要 PyYAML：

```sh
python3 samples/world-cup/bkn-eval/scripts/recalculate.py --check
```

合并独立 Agent 的输出后，可以用评分脚本逐题核对：

```sh
python3 samples/world-cup/bkn-eval/scripts/grade_answers.py /absolute/path/answers.json
```

输入格式为 `[{"id":"B-01","rows":[...]}]`，包含全部 50 题。脚本按问题集规定的字段和行序核对，整数计数严格相等，舍入比率使用规定容差；缺题、缺字段、漏掉并列者、排序错误或重复题号均不能通过。评分结果默认输出到终端，执行记录另存本地。

脚本直接读取本地冻结 CSV，检查 27 个文件的 SHA256、问题与参考规格、输出列及答案。参考 SQL 仅用于本地 CSV 校准，不会访问平台或提供给被测 Agent。

`answer-set-v1.yaml` 记录数据源提交、数据锁、问题集及参考规格的摘要，同时明确列出上述未声明展示字段。除已知的这 20 个字段外，新增的模型与 CSV 差异会使校验失败。

评测题、参考答案及可重算脚本保留在源码仓库，按现有打包规则不进入运行时安装包。执行记录、MCP 返回值和独立 Agent 的临时计算文件留在本地。
