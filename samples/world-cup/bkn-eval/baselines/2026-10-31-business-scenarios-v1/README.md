# 业务场景测试集 v1

依据[业务 PRD](../../../docs/PRD.md)的场景和业务口径编写，共 50 题：基础 12、中等 20、复杂 18；分别从体育编辑、球队分析师和赛事数据管理员的角度提问。题目用业务语言，不在题干里写字段、排序和计算规则。题意沿用原 50 题，参考答案与原参考答案逐题一致。

- `question-set-v1.yaml`：题目、场景、难度、角色与输出要求。被测智能体只能看到这一份。
- `answer-set-v1.yaml`：机器可读的期望值。被测智能体不得读取。
- `oracle.py` 与 `reference-queries.json`：把锁定的 CSV 载入 SQLite，逐题运行参考 SQL，不访问平台。`question-text.yaml` 是本语言的题目文字。中英文包数据相同，`oracle.py` 和参考 SQL 完全相同，期望值一致。

```sh
python3 samples/world-cup/bkn-eval/baselines/2026-10-31-business-scenarios-v1/oracle.py
```

人名、队名、奖项名是数据源英文原文，中文题的答案也以英文原文和编号为准。
