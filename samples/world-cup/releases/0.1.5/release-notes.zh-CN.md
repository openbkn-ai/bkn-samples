# 0.1.5

- 新增三个原生函数，挂载到世界杯知识网络：`射手榜`（按非乌龙球进球竞赛排名，保留并列）、`球员生涯`（参赛届数、逐届进球、奖项）、`赛事概况`（比赛数、比分进球、场均进球、乌龙球、点球大战罚球）。
- 每个函数是一个可读的独立源文件，通过沙箱预装的 `bkn_osdk` 调用 `run_cypher` 和 `query_object_instance` 读取知识网络；网关地址和凭据由运行时提供，代码中不写地址。
- 安装校验会实际调用 `射手榜`，核对 WC-2022 射手王为 P-64077（8 球）。
- 数据和知识网络模型不变。旧安装请先卸载，再安装此版本；不提供原地迁移。
