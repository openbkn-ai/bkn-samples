# 世界杯历史数据：赛事、球队、球员与比赛事件 PRD

## 业务目标与使用者

基于 Joshua C. Fjelstul 公开的世界杯数据库（男足截至 2022 年、女足截至 2019 年），让使用者直接用业务语言查询世界杯历史：哪届谁夺冠、某场比赛怎么踢的、谁进了多少球、哪支球队和哪个足联表现最好，并看到结论依据的赛事、比赛、球队、球员和事件记录。

| 使用者 | 关心的问题 | 期望得到的结论 |
|---|---|---|
| 体育编辑 | 赛事概况、射手榜、奖项、经典比赛和球星对比 | 冠军与主办国、进球与排名、获奖记录、比赛经过 |
| 球队分析师 | 球队比赛历程、积分榜、进球构成、点球大战、换人和纪律 | 逐场结果、名次、进球拆分、罚球结果、换人和红黄牌 |
| 赛事数据管理员 | 数据范围、记录条数、各类记录是否对得上 | 届数、场数、球队和球员数、各届明细覆盖、比分与进球记录核对 |

成功标准：使用者提问时不需要说明计算规则，就能得到符合本文口径的结论和依据。规则必须写在问题里才能答对、换个说法就答错，不算达标。

## 数据范围

纳入：赛事、主办国、赛事阶段、小组与积分榜、最终排名、足联、球队、出线资格、大名单、球员、教练与任命、裁判与任命、球场、比赛、球队出场、球员出场、教练出场、裁判执法、进球、点球大战罚球、红黄牌、换人、奖项与获奖者。

不纳入：赛事以外的俱乐部和国家队比赛；数据源没有的统计（如射门、控球、扑救）；对缺失记录的推测。数据源人员、球队、奖项等名称是英文原文，保留原拼写和重音符号。

## 业务口径

以下是默认规则，使用者提问时不必重复；使用者明确提出别的条件时，以使用者为准。

1. **数据范围**：男足世界杯截至 2022 年（22 届），女足截至 2019 年（8 届）。赛事名称含 Women's 的是女足。各类明细记录覆盖的届次不同，没有记录不代表现实中没有发生，例如 1999 年女足世界杯没有球员出场记录。
2. **比赛与球队出场**：比赛按场计数，每场一次；球队出场记录每场有两条（双方各一条）。出场次数按不同比赛计数。
3. **进球**：球员进球不含乌龙球；球队进球按记入球队计算，包含对方打进的乌龙球。比赛中的点球算进球；点球大战罚球不算进球，也不计入比分。
4. **比分与胜负**：比赛比分不含点球大战，点球大战比分单列。胜负平以球队出场记录的胜、负、平标记为准，不自行改判；点球大战决出的比赛在记录里通常是平局。分差是比赛比分之差的绝对值。
5. **红黄牌**：黄牌、红牌、两黄变一红、罚下各自统计；同一次处罚可能同时带多个标记，不能相加当成总处罚次数。
6. **排名**：射手榜、胜场榜等用竞赛排名，同分同名次、后续名次跳过；“前 N 名”返回名次不超过 N 的全部球员或球队，含边界处并列者。问“N 座、N 个”这类数量时恰好取 N 个，同值按编号排序。按足联等类别统计时列出全部类别，没有记录的计 0。
7. **人名与身份**：全名 = 名 + 空格 + 姓，按数据源英文原文返回；同名人物以编号区分。
8. **决赛与阶段**：比赛阶段以赛事阶段记录为准；1950 年世界杯没有决赛，冠军由决胜循环赛决出。
9. **主办国**：联合举办的赛事每个主办国单独列出。
10. **点球大战**：只能说罚进或未罚进，不能当成守门员扑救次数。
11. **平均值**：场均进球、场均黄牌等保留三位小数。

## 业务场景

| 场景 | 使用者的问题 | 期望得到的结论 |
|---|---|---|
| S01 赛事概况 | 有几届、谁办的、谁夺冠 | 届数、场数、主办国、冠军、特殊赛制 |
| S02 球队与足联 | 球队和足联表现如何 | 参赛球队、进球最多的球队、胜场排名、足联胜场 |
| S03 球员、大名单与奖项 | 谁入选、谁出场、谁获奖 | 大名单、出场次数、奖项、球星对比 |
| S04 进球与射手 | 谁进球、进了多少、怎么进的 | 射手榜、进球拆分、点球进球、首发与替补进球 |
| S05 比赛与比分 | 某场比赛和某届比赛的比分 | 决赛对阵与比分、大比分比赛、场均进球、比分与进球记录核对 |
| S06 纪律 | 红黄牌有多少 | 各届与各队的红黄牌 |
| S07 教练与裁判 | 谁执教、谁执法 | 主教练、场边教练、主裁判、执法场次排名 |
| S08 积分榜与比赛历程 | 球队怎么一路走来、最终名次 | 小组积分榜、逐场历程、跨届对比 |
| S09 点球大战与换人 | 点球大战和换人经过 | 罚球顺序与结果、对手罚球结果、换人时间 |
| S10 场馆与数据覆盖 | 球场和数据覆盖情况 | 最大球场、各类记录条数 |

## 验收标准

1. 每种语言 50 题，覆盖上述 10 个场景：基础 12、中等 20、复杂 18。全部用业务语言提问，题干不写计算规则。
2. 复杂题至少同时涉及两条业务口径，或需要跨三类以上记录推理。
3. 参考答案用参考 SQL 直接从锁定的 CSV 计算，独立于被测能力；被测方看不到答案。
4. 每种语言跑一轮，目标准确率 100%。
