# World Cup 0.1.0

Initial release of a standalone English World Cup sample with 27 locked CSV tables, 410 modeled fields, 29 relationships and four concept groups.

Independent external agents use standard MCP schema and object-instance tools to acquire facts and perform analysis. The sample does not register SQL tools, custom functions, metrics or executable business Skills, and does not invoke a platform-internal agent.

Includes 50 scenario questions and reproducible reference answers, covering basic statistics, joins, rankings, cross-tournament comparisons and combined analysis. Explicit rules cover ties, own goals, shootouts, match grain and detail-table coverage.

Uses the standard OpenBKN managed installation flow, with database and network `worldcup_en`.

The data snapshot ends at men’s 2022 and women’s 2019. Detailed event coverage varies; missing rows must not be interpreted as missing real-world participation. Online availability requires separate fixed-artifact publication and catalog registration.
