# 金融投资组合运营（FIBO 参考，中文）

以虚构资产管理机构的证券交易后控制为场景，从金融工具、法律实体和组合，追溯到成交、结算、持仓、价格、估值、发行方集中度和未结算卖出应收限额。包含 20 张数据表、本体、3 个原生函数和 2 个业务 Skill。业务需求与口径见 [PRD](docs/PRD.md)。

## 安装与体验

1. 登录 OpenBKN，进入首页的**一键体验**。
2. 刷新官方目录，选择**金融投资组合运营**并点击**安装**，要求 **OpenBKN >=0.2.1 <0.3.0**。
3. 等待安装和验证完成，打开对应知识网络。
4. 在智能问答、数据查询和图探索页面试用体验卡，或接入外部 Agent，通过 MCP 查询对象、调用已发布函数和使用 Skill。

无法访问官方目录时，从 [Releases](https://github.com/openbkn-ai/bkn-samples/releases) 下载本样例的 `package.tar.gz`，在一键体验中选择**导入离线包**后安装，详见[离线安装说明](docs/offline-installation.md)。

数据是虚构的合成数据，覆盖 2026 年 11 月至 2027 年 3 月，业务日期为 2027-02-28：十一月至二月为实际，三月为当天已知的计划。不代表真实市场数据、官方净值或监管风险计量，不下单也不修改任何记录。

## 能力

能用 Cypher 查到的不写函数，只为 Cypher 表达不了的重算保留函数。样例不使用指标，社区版即可完整使用。

- **Cypher 查询**：主数据、成交与交收、月末持仓、估值、发行方敞口及构成、交易对手应收、限额评估、限额版本。月末快照与按原始记录重算的结果一致，可直接读取。
- **原生函数**：`settlement_asof`、`valuation_asof`、`limit_assessment_asof`，按指定日期和当天已知信息，从原始成交、交收事件、价格和限额重算交收状态、持仓估值和限额判断，用于非月末日期或回看更早某天的情况。
- **Skill**：按使用者组织为“交易后运营”（中台、会计）和“风控与限额”（风控、组合经理），写明业务口径、何时用 Cypher、何时调用函数和回答格式。

## 体验卡

体验卡从测试集中选题，覆盖交收、估值、集中度、对手应收、未来限额和时点回看，由浅入深。卡片的数据查询和图探索 Cypher 用 `tools/acceptance/experience_set.py` 在安装后的平台上在线核验。

## 验收与维护

测试集见 [业务场景测试集 v1](bkn-eval/baselines/2026-10-30-business-scenarios-v1/README.md)，参考答案由独立脚本从交付数据计算，不随安装包交付。安装后让未读答案的智能体每题跑一轮；未达 100% 时记录失败原因，先改本体描述、Skill 或函数，不改题目和答案迁就结果。原有 100 题回放与数据核验见 [bkn-eval](bkn-eval/README.md)。

本体与 FIBO 的对应见[本体规范](docs/bkn-modeling-spec.md)和 [FIBO 语义映射](docs/fibo-operational-mapping.md)；来源为 [EDM Council FIBO](https://github.com/edmcouncil/fibo) 固定修订 `2d73435a4419b66b7c9f44cb9763e35fe8ac7890`，MIT 许可，原始 RDF 见 [fibo-reference/](fibo-reference/README.md)。

升级时先卸载旧样例，再安装新版本。卸载会清理样例数据和用户修改；删除离线包缓存不会卸载已安装资源。
