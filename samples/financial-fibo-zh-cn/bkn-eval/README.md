# 本地验收集

100 道独立题目分布于 10 个业务验收场景。`questions.json` 保留问题、难度、场景 ID、关系路径和只读证据 SQL；`expected-results.json` 固定全部结果行；`answers.md` 供人阅读。逐题结果需保持行顺序、字段和空值语义；数字按显式容差比较。

`run.py` 先检查数据摘要和 BKN 映射，再以独立 Decimal 算法验证金融逻辑，最后在内存 SQLite 回放全部题目。数据库限制为只读查询，不使用生成器或运行中重生成预期答案。实际智能体/MCP问答须针对固定离线包在平台另行执行，原始问答和事后评分与本地回放证据分开保存。
