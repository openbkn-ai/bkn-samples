# 业务场景测试集 v1

依据[业务 PRD](../../../docs/PRD.md)的场景和业务口径编写，共 50 题：基础 12、中等 20、复杂 18；分别从中台运营、基金会计、风控合规和投资组合经理的角度提问。题目用业务语言，不在题干里写计算规则。

- `question-set-v1.yaml`：题目、场景、难度、角色与输出要求。被测智能体只能看到这一份。
- `answer-set-v1.yaml`：机器可读的期望值。被测智能体不得读取。
- `oracle.py`：只读本包 `data/` 下的交付 CSV 和 `model-contract.json`，用 Decimal 独立计算全部答案并生成上面两份文件；不导入或调用样例函数，也不读取历史答案。中英文包使用同一份脚本，数据只在文字上不同，所以期望值除名称和状态文字外完全一致。

```sh
python3 samples/financial-fibo-zh-cn/bkn-eval/baselines/2026-10-30-business-scenarios-v1/oracle.py
```
