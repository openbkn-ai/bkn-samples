# FIBO 原始来源

六份选定模块的原始 RDF 保存在 `sources/`，`source-lock.json` 固定仓库修订和各文件 SHA-256；`LICENSE-FIBO.txt` 是原 MIT 许可。`classes.json` 是 171 个具名类的来源清单；`properties.json` 是 71 个具名对象/数据属性清单。清单记录来源文件、英文定义、类型和废弃状态。它们用于语义溯源，不作为虚构运营数据的对象实例或全量 FIBO 导入声明。

[Official source / 官方来源](https://github.com/edmcouncil/fibo/tree/2d73435a4419b66b7c9f44cb9763e35fe8ac7890)
