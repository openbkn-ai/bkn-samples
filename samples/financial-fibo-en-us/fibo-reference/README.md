# Original FIBO sources

`sources/` retains six selected original RDF modules. `source-lock.json` pins repository revision and each SHA-256; `LICENSE-FIBO.txt` is the original MIT license. `classes.json` inventories 171 named classes; `properties.json` inventories 71 named object/data properties, with source files, English definitions, kind and deprecation. These support semantic provenance, not operational instances or a full-FIBO import claim.
