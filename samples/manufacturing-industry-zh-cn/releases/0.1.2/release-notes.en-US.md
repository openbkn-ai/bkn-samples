# 0.1.2 — OpenBKN 0.2.1 candidate

Deliver a content-only shared-MariaDB package without a sample-specific data image. Match decimal, integer and date SQL types to the model and verify every typed source row. Add ownership checks before model import, explicit table bindings and live-query verification hooks. Preserve the 40 operational tables, 71 relations, IOF reference layer and 100-question bank.

Fixed-source offline candidate; local validation does not establish platform or native amd64/arm64 runtime acceptance. Requires OpenBKN >=0.2.1 <0.3.0 with the shared sample database and compatible executor. Existing installations require uninstall then install; no in-place migration. Not admitted to a stable catalog. Historical archives are unchanged.
