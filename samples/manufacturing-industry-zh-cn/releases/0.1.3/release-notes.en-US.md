# 0.1.3 — OpenBKN 0.2.1 candidate

Resume resource binding after an interrupted owned-network import. Inspect every
object before changing any binding; retain matching bindings, fill only unbound
objects, and reject foreign bindings. Verification remains read-only. Data, models
and business definitions are unchanged. Local retry/conflict tests cover both
languages; actual OpenBKN instance acceptance remains pending. Prior package assets
are immutable; this is a new candidate version.
