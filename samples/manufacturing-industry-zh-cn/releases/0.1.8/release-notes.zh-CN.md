# 0.1.8：显示名（OpenBKN 0.2.2）

让 Workshop 调度向导、甘特和问答里看到的是业务名称，而不是字段 ID。数据、规则口径和行动行为与 0.1.7 相同。

- **属性显示名**：40 个对象的全部 240 个属性都有显示名，中文版为中文（如计划开始日、计划机台、标准工期（天）、状态、设备编号、设备名称），英文版为英文（Planned Start Date、Planned Machine、Status 等）。属性 ID 不变。
- **关系显示名**：73 条关系都按连接字段命名，中文版如“制造操作的生产工单”“制造操作的前序工序”“制造操作的计划机台”，英文版如“Manufacturing Operation → Production Order”。关系 ID 不变，Cypher 写法不变。
- **工具箱与函数名**：规则函数和行动执行函数分成两个工具箱。中文版为“制造业排程规则”（工单齐套、设备能力、人员资质与班次、换型提示，直接挂载在知识网络上）和“制造业排程调整”（调整工序排程、调整维修工单，供两个行动使用）；英文版为 Manufacturing_Schedule_Rules 和 Manufacturing_Schedule_Adjustments（工具箱和函数名只能用中文、字母、数字和下划线），函数名如 Work_Order_Kit。不再使用 MANUFACTURING_zh_cn_Schedule 这类 ID 式名称。
- **安装失败也能卸载**：安装钩子在创建第一个资源前先写下空的资源归属记录；以前若在建工具箱前失败，样例服务会因记录不全拒绝卸载。
- **安装更稳**：安装步骤只试查刚载入的两个数据集对象，全部 40 个对象的实例试查留在验证步骤（各自 300 秒）；平台每次调用较慢（1–2 秒）时安装也能在时限内完成。
- 从 0.1.7 升级需先卸载 0.1.7 再安装（卸载会删除旧工具箱）。bkn-eval 原有 50 题答案不变。

样例自带的 Workshop“机台排产”应用不在本版本内。
