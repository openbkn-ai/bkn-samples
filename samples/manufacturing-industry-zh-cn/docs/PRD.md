# 精密加工订单履约：计划、生产、质量与采购 PRD

## 业务目标与使用者

虚构的精密加工企业在深圳和苏州两个工厂为十家客户加工泵壳、阀体、叶轮和法兰。订单、物料、生产执行、质量和设备维护记录分散在不同系统里，业务人员需要直接用业务语言问清：订单能不能按时交、卡在哪里，已经做完的活是不是在合规条件下做的，检验能不能支持放行，哪些采购和设备会影响后面的生产，并看到每个结论依据的订单、工单、发料、执行、检验和发运记录。

| 使用者 | 关心的问题 | 期望得到的结论 |
|---|---|---|
| 订单交付经理 | 哪些订单欠交、延误、为什么，三月订单能不能开工 | 欠交数量、延误天数、阻塞原因、补做工单 |
| 生产主管 | 工单进度、产出和报废，执行是否由合格的设备和人员在安排的班次完成 | 工单状态、良率、不合规的执行及原因 |
| 质量经理 | 检验能否支持放行，有没有超规格却被放行的批次 | 拒收批次、超限项、质量漏检、规格版本 |
| 采购与物料经理 | 物料够不够、哪些采购逾期或拒收、有没有违规发料、库存还剩多少 | 缺料、逾期采购、拒收来料、待检发料、可用库存 |

成功标准：使用者提问时不需要说明计算规则，就能得到符合本文口径的结论和依据。规则必须写在问题里才能答对、换个说法就答错，不算达标。

## 决策范围

纳入：工厂、工作中心、产品、BOM 版本、工艺路线、设备与能力、操作员资质与班次、客户与销售订单、需求预测与生产计划、工单与物料需求、采购与来料、发料、执行记录、检验批与检验结果、质量规格、成品入库、发运、库存和设备维护。

不纳入：真实下单、排产、派工、放行或发货；有限产能排程和最优排序；成本与价格；批次和序列号谱系；不合格品处置。所有结论只作建议。

## 业务口径

以下是默认规则，使用者提问时不必重复；使用者明确提出别的条件时，以使用者为准。

1. **业务日期**：2027-02-28。“现在、今天、目前”都指这一天。2026 年 11 月至 2027 年 2 月的记录已经发生，三月的工单是计划；库存是 2027-02-28 的快照。
2. **订单与交付**：每个销售订单行由工单生产；工单检验被拒后，可以由补做工单为同一订单行重做。欠交 = 订购数量 − 已发运数量，大于零即欠交。订单行全部发完后，最后一次发运晚于要求交期即延误，延误天数 = 最后发运日期 − 要求交期；要求交期已过仍未发完的也算延误。
3. **物料需求与齐套**：物料需求 = 工单数量 × 单耗 × (1 + 损耗率)，向上取整。已发数量不低于需求即齐套。只能从已接受的来料发料；从待检或拒收的来料发料属于违规发料。
4. **工单能否开工**：工单所用 BOM 版本已冻结，且到计划开工日（生产计划行的计划开始日期）全部物料齐套。BOM 未冻结，或计划开工日已到而任一物料不齐套，工单阻塞，要说明是哪种原因；计划开工日未到、还没发料的工单不算阻塞。
5. **执行合规**：每条已开始的执行都要同时满足四项，任何一项不满足即不合规：
   - 设备具备该步骤要求的能力，且能力状态为合格；
   - 设备在执行开始当天没有维护工单；
   - 操作员对该能力的资质为合格，且有效期不早于执行开始日；
   - 操作员在执行开始日所在周的班次中，被安排在该工序所在的工作中心。
6. **产出与良率**：工单完成数量 = 最后一道工序的合格数量；工序良率 = 合格 ÷ (合格 + 报废)；工单良率 = 完成数量 ÷ 工单数量。
7. **质量放行**：最终检验批为已接受，且每项测量值都在所引用规格的上下限之内（含边界）才算合格。检验结果记为通过但测量值超限的，按不合格计，属于质量漏检。检验以结果所引用的规格版本为准；问产品现行规格时看状态为生效的那条。
8. **成品与发运**：只有已接受的成品入库才能发运；发运数量不超过入库数量和订单数量。
9. **采购与来料**：来料按采购订单的预计到货日期考核，到货日期晚于预计即延迟到货；预计到货日期早于业务日期、已接受数量仍不足订购数量的采购订单为逾期未到。拒收的来料不算到货。
10. **库存**：可用 = 在手 − 已分配。待检区的库存不能发料。
11. **设备维护**：计划日期早于业务日期且未完成的维护工单为逾期；状态为维修中的设备不能安排生产。
12. **预测与计划**：生产计划按工单交期所在月份汇总，与该月需求预测比较；计划覆盖率 = 计划数量 ÷ 预测数量。

## 业务场景

| 场景 | 使用者的问题 | 期望得到的结论 |
|---|---|---|
| S01 产品与产能 | 做哪些产品、用什么料、走哪些工序、有哪些设备和人员 | BOM、工艺路线、设备能力、人员资质 |
| S02 订单与交付 | 欠客户多少、哪些延误、拖了多久 | 欠交、延误天数、分批发运、补做工单 |
| S03 预测与计划 | 计划能不能覆盖预测 | 各月各产品计划覆盖率、计划不足的产品 |
| S04 物料齐套 | 料够不够、哪些工单因缺料或 BOM 阻塞 | 物料需求、缺口、阻塞原因 |
| S05 采购与来料 | 哪些采购逾期、拒收、延迟，有没有违规发料 | 逾期采购、拒收来料、延迟供应商、待检发料 |
| S06 生产进度与产出 | 工单做到哪一步、产出和报废多少 | 工单状态、完成数量、良率、报废工序 |
| S07 执行合规 | 已完成的活是不是合规条件下做的 | 不合规的执行及原因、涉及的工单和人员 |
| S08 质量放行 | 检验能不能放行、有没有漏检 | 拒收批次、超限项、质量漏检、规格版本 |
| S09 设备维护 | 哪些维护逾期、哪些设备不能用 | 逾期维护、维修中设备、维护与生产冲突 |
| S10 端到端追溯 | 一张订单从下单到发运经过了什么 | 订单 → 工单 → 发料 → 执行 → 检验 → 入库 → 发运的完整链路 |

## 验收标准

1. 每种语言 50 题，覆盖上述 10 个场景：基础 12、中等 20、复杂 18。全部用业务语言提问，题干不写计算规则。
2. 复杂题至少同时涉及两条业务口径，或需要跨三类以上记录推理。
3. 参考答案独立于被测能力计算，被测方看不到答案。
4. 每种语言跑一轮，目标准确率 100%。
