# 需求响应运营：容量承诺、调度与结算 PRD

## 业务目标与使用者

虚构的“澄源负荷聚合”替 50 家企业管理空调、冷链制冷和充电设施的可调负荷，在电网发布削减需求时组织响应、核实交付并结算。业务人员需要直接用业务语言问清：能承诺多少、哪些设备能参加、几个事件抢同一批资源怎么排、实际交付了多少、收入和客户补偿对不对，并看到每个结论依据的事件、设备、分配、读数和日期。

| 使用者 | 关心的问题 | 期望得到的结论 |
|---|---|---|
| 聚合商运营负责人 | 能不能接下需求、承诺后会不会挤占其他事件、按成本怎么排 | 可承诺容量、已承诺、可新增、缺口和预计成本，算不清的原因 |
| 企业能源经理 | 削减不能破坏最低保障负荷，检修或退出的设备不能进计划 | 设备和场所上限、禁止响应和撤回的申报、受影响的事件 |
| 响应值班员 | 分配是否真的执行了、计量是否可靠 | 执行回执、核实电量、交付比例、缺失或更正的读数 |
| 结算专员 | 达标判断、收入和客户补偿是否按同一规则核算，是否与台账一致 | 收入、补偿、净额、与已入账金额的差额和不能核对的原因 |

成功标准：使用者提问时不需要说明计算规则，就能得到符合本文业务口径的结论，并看到依据的记录。规则必须写在问题里才能答对、换个说法就答错，不算达标。

## 决策范围

纳入：客户、场所、设备与电表；响应事件；负荷预测与核定基线；设备申报；设备约束（禁止响应、限额）；调度分配与执行回执；电表读数；结算台账；容量快照与结算快照。

不纳入：真实下发指令、控制设备或付款；发电、储能优化和潮流计算；秒级调控和区段内爬坡；法定电力市场结算规则。所有结论只作建议。

## 业务口径

以下是默认规则，使用者提问时不必重复。使用者明确提出别的条件时，以使用者为准。

1. **业务日期**：2027-02-28，“现在”“今天”指这一天。十一月至二月的事件已经发生，三月份的事件是已公告的计划。响应时段 peak_a 为 2 小时、peak_b 为 3 小时；同一天同一时段的事件完全重叠，不同时段不重叠。
2. **按某天的情况**：只算当天已公告的事件和当天已经知道的记录；后来才知道的更正，按更早的信息看不算。
3. **版本**：预测、基线、读数按设备（电表）、日期、时段取当天可见的最新版本；申报按事件和设备，执行回执按分配。同一版本内容一致的重复提交只算一次；同一版本内容冲突时结果算不清。最新版本无效时不能退回用旧的有效版本。
4. **单位与精度**：功率千瓦，电量千瓦时 = 千瓦 × 时段小时数，单价元/千瓦时。先用精确值汇总，最后四舍五入：数量和比例保留 6 位，金额保留 2 位。
5. **未知不等于零**：缺少必需的预测、基线、读数或回执，或内容冲突时，相关结果算不清，不能当成零；分母为零的比例为空。
6. **可承诺容量**：每台设备取以下最小值：申报量、设备最大削减量、预测与基线中较小者减去最低保障负荷（不低于零）、当天有效的限额。设备停用、当天被禁止响应、申报撤回或不在有效期内的计零；限额缺上限值时算不清。每个场所合计不超过场所响应上限，事件容量为各场所之和。每台设备只有一块电表，不和场所总表叠加计量。
7. **调度方案**：同一天同一时段的有效事件共用设备和场所的削减上限。已承诺的分配先占用；新增按事件优先级、再按申报成本从低到高安排，不超过事件目标、设备可承诺量和剩余上限。同一时段只要有事件的容量算不清，或已承诺的分配超出设备上限或当前可承诺量，整个时段的新增方案就给不出完整结果。预计成本包含已承诺和新增部分。
8. **交付核实**：只有执行回执为“完成”的分配算交付；失败或客户退出的算零，缺回执的算不清。实际削减电量 = 最新核定基线 × 小时数 − 最新有效读数，不低于零；同一设备同一时段承诺给多个事件时，按承诺电量比例分摊，合计不超过实际削减电量。交付比例 = 核实电量 ÷ 承诺电量，承诺为零时比例为空。
9. **收入与补偿**：交付比例达到最低要求（含等于）时，收入 = 核实电量 × 事件奖励单价，否则收入为零；客户补偿 = 各设备分摊电量 × 申报成本单价，不论是否达标都要付；收入和补偿分别保留到分，净额 = 收入 − 补偿，可以为负。未来事件还不能结算，已取消的事件不结算。
10. **台账核对**：取入账日期不晚于当天的最新一笔已入账结算与重算收入比较；没有入账为空，不是零；同一天有两笔内容冲突的入账则不能核对。
11. **快照**：容量快照和结算快照记录 2027-02-28 的结果，标为无效的不能用；标为有效的也要和按原始记录重算的结果核对，差异要说明。

## 业务场景

| 场景 | 使用者的问题 | 期望得到的结论 |
|---|---|---|
| S01 资产 | 有哪些客户、场所和设备，上限和电表是什么 | 数量、场所上限、设备削减和保障负荷、停用设备 |
| S02 预测与计划 | 三月有哪些事件，预测能不能用 | 事件安排、目标、最新预测是否有效 |
| S03 可承诺容量 | 能承诺多少，哪些设备不能参加，为什么算不清 | 事件容量、禁止响应和撤回申报、缺上限或无效预测 |
| S04 场所上限 | 场所上限压掉了多少，会不会重复计量 | 超上限的场所、电表唯一性 |
| S05 共享资源 | 同一时段的事件怎么分资源，有没有超额承诺 | 共享分配、超额设备、按优先级的新增与缺口 |
| S06 按成本安排 | 新增安排哪些设备、成本多少、能不能凑够 | 新增设备和千瓦、预计成本、缺口 |
| S07 执行与交付 | 指令执行了没有，交付了多少 | 回执、核实电量、交付比例、未达标事件 |
| S08 更正与回看 | 晚到的更正、冲突和重复会怎样改变结果 | 不同日期掌握信息下的核实电量和收入，受影响事件 |
| S09 结算与台账 | 收入、补偿、净额是多少，和台账一致吗 | 收入、补偿、净额、台账差额和不能核对的原因 |
| S10 计划与快照 | 未来事件能否结算，快照能不能信 | 无效和对不上的快照、计划完整性、结算卡在哪里 |

## 验收标准

1. 每种语言 50 题，覆盖上述 10 个场景：基础 12、中等 20、复杂 18。全部用运营、能源经理、值班或结算人员的业务语言提问，题干不写计算规则。
2. 复杂题至少同时涉及两条业务口径，或需要跨三类以上记录推理。
3. 参考答案独立于被测能力计算，被测方看不到答案。
4. 每种语言跑一轮，目标准确率 100%。
