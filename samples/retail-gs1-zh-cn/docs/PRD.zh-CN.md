# 食品供应链运营：批次追溯、库存履约与召回 PRD

## 业务目标与使用者

一家食品零售企业有 25 个仓库和 25 家门店，经营乳制品、烘焙、饮料、谷物和休闲食品。批次从供应商到货、质检、入库，在仓店之间调拨，在门店销售或退回；出现质量问题时要发起召回。业务人员需要直接用业务语言问清：货在哪、能不能用、够不够、召回影响多大，并看到每个结论依据的批次、事件和日期。

| 使用者 | 关心的问题 | 期望得到的结论 |
|---|---|---|
| 质量负责人 | 哪些批次不合格或被召回，问题货在哪、卖出去多少、控制住多少 | 质检结果、隔离和召回封存数量、流向、已售未退数量、控制比例 |
| 仓配负责人 | 仓里真正能用多少，订单够不够分，三月要补多少 | 可用库存及原因拆分、订单逐行分配与缺口、按预测的补货量 |
| 门店店长 | 店里能卖多少，哪些快过期或已过期，召回影响哪些订单 | 门店可用量、近效期和过期批次、受影响订单 |

成功标准：使用者提问时不需要说明计算规则，就能得到符合本文业务口径的结论，并看到依据的批次、事件和单据。规则必须写在问题里才能答对、换个说法就答错，不算达标。

## 决策范围

纳入：商品、组织与地点主数据；批次与质检；收货、调拨、在途、销售、退货等出入库事件；隔离；订单与预留；需求预测与计划到货；批次拆分与转换；召回及召回快照、库存快照。

不纳入：真实下单、出库或付款，运输路线，预测模型，自动召回通知，法规认证和财务结算。所有结论只作建议。

## 业务口径

以下是默认规则，使用者提问时不必重复。使用者明确提出别的条件时，以使用者为准。

1. **业务日期**：2027-02-28，“现在”“今天”指这一天。三月份的需求预测和计划到货是今天已知的计划，不能当成已经发生。
2. **按某天的情况**：只算事件日期不晚于当天、并且记录日期不晚于当天的实际事件；后来才补录的事件，按补录前的信息看就不算。
3. **事件可信度**：同一事件被重复记录只算一次；被冲正的事件不算；同一事件出现内容冲突、到货找不到发货、算出负库存、退货多于销售时，相关批次库位的库存算不清，不能当成零。
4. **数量**：一律按商品基准单位（件）计；按箱记录的乘以每箱件数。
5. **在库与在途**：收货、生产、到货、退货增加在库；销售、消耗、发货减少在库；已发出未到货的是在途，不算在库。
6. **隔离**：质检不合格或还没检完的批次全部隔离；此外，退货和有效的隔离单也要隔离，同一批货不重复扣。
7. **召回封存**：进行中的召回从根批次开始，沿批次拆分和转换找到所有下游批次；这些批次扣掉隔离后剩下的在库全部封存。已关闭的召回不再封存。
8. **可用库存**：在库减去隔离、召回封存和有效预留；已过期的批次可用为零；预留最多只扣到可用为零，超出部分是超额预留。两周内到期的为近效期。
9. **订单分配**：未完成订单按优先级、交期、订单号先后，共用同一份可用库存；每行只用同地点、同商品、已检合格、按“今天和交期较晚者 + 最少剩余保质天数”仍未过期的批次，先到期先出；订单自己的预留可以用回给自己。已经过了交期但没完成的订单也要分配。
10. **补货**：按三月预测逐次扣减可用库存和到期前的合格计划到货，先到期先用；到需求日期时已不满足剩余保质期的货不算；缺口就是建议补货量。
11. **召回控制**：按商品和地点计算。可控制量 = 受影响批次的在库 + 在途；已控制量 = 其中已隔离的数量；控制比例 = 已控制 ÷ 可控制，可控制为零或库存算不清时比例算不出来，不是零。已卖出的按销售减退回计，单独列示。

## 业务场景

| 场景 | 使用者的问题 | 期望得到的结论 |
|---|---|---|
| S01 商品与地点 | 卖什么、谁供货、有几个仓几家店 | 商品与品类、供应商、包装、保质期要求、仓店数量 |
| S02 到货与质检 | 哪些批次不合格或没检完、还在哪 | 质检结果、问题批次的在库分布、能否销售 |
| S03 批次流向 | 货从哪来、去了哪、拆成了什么 | 出入库事件、调拨来源、拆分子批次、召回批次到过的地点 |
| S04 库存与在途 | 真正能用多少、为什么少 | 可用、在途、隔离数量，按批次拆分的原因 |
| S05 效期 | 哪些快过期、哪些已过期还在库 | 近效期和过期批次清单、过期库存量 |
| S06 订单履约 | 订单够不够分、缺多少 | 逐行分配、用哪些批次、缺货订单与缺口 |
| S07 补货计划 | 三月要补多少、从哪次开始缺 | 预测量、补货量、各需求日期的缺口、缺口最大的商品 |
| S08 召回影响 | 召回涉及哪些批次、地点、订单 | 下游批次、在库分布、已售未退、受影响订单 |
| S09 召回控制 | 控制住多少、还差多少 | 已控制、可控制、控制比例、未控制量、关闭召回的处理 |
| S10 数据可信与回看 | 哪些数据有问题、不同日期看到的结论有何不同 | 算不清的库存及原因、重复和冲正事件、补录前后的对比 |

## 验收标准

1. 每种语言 50 题，覆盖上述 10 个场景：基础 12、中等 20、复杂 18。全部用质量、仓配或门店负责人的业务语言提问，题干不写计算规则。
2. 复杂题至少同时涉及两条业务口径，或需要跨三类以上记录推理。
3. 参考答案独立于被测能力计算，被测方看不到答案。
4. 每种语言跑一轮，目标准确率 100%。
