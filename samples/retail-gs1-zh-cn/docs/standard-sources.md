Conceptual mappings: organizations → https://ref.gs1.org/voc/Organization; locations → https://ref.gs1.org/voc/Place; products → https://ref.gs1.org/voc/FoodBeverageTobaccoProduct. Operational descriptions are paraphrases; synthetic identifiers are not GLNs/GTINs. No owl:equivalentClass or certification claim. Complete mapping inventory is model-map.json.

[EPCIS/CBV official artifacts](https://ref.gs1.org/standards/epcis/artefacts) inform traceability/event terminology. This package contains original synthetic records, not redistributed EPCIS specifications or official example data. It is not a full EPCIS server. Other object types are explicit local operational extensions.
