# 零售供应链业务验收题库

固定100题，对应PRD十个场景：Q001–010/S01至Q091–100/S10。每语言基础30题、中等40题、复杂30题。场景需求以PRD为准，不另设重复需求文档。

`questions.json` 仅含自然语言题目、范围及输出契约，不包含答案或计算配方。`expected-results.json`、`answers.md` 是评测专用答案和来源证据；`oracle-recipes.json` 记录独立评测计算方法。这些资料不得装入业务样例或暴露给答题代理。`freeze.json` 固定题库摘要，正式验收另固定数据、安装包和判分器摘要。

独立答案实现位于 `tools/retail_eval/oracle.py`，不导入生产函数、不用生产函数输出生成答案。它根据源CSV及公开业务规则，分别实现重复/撤销事件、双时间库存、退货隔离显式重叠、预留、共享库存FEFO、带日期补货与单向召回范围。指标题明确区分记录快照与原子事实重算。

五个有意设计的空列表分别检查无角色错误、无拆分数量不匹配、公告尚不可知、召回已关闭及无外键/单位/序号完整性错误；其他95题都有来源事实支持的非空结果。未知数量必须为空，不能用空结果替代调用失败或缺失证据。

开发期校验（不属于正式问答轮次）：

```sh
python3 tools/retail_eval/validate_bank.py
```

该检查核对全部答案与独立源计算、双语数值一致、证据ID、人工推导业务控制及判分器反例，不代表代理问答准确率。`build_bank.py --write` 用于编写/生成，正式冻结后禁止执行。

正式验收由全新的隔离子智能体通过8081已安装网络进行，中英文各100题，每题一次、各一轮。答题者只能读取公开题目、实时本体与能力，不得读取本地CSV、独立计算器、答案或历史回答。首次回答、工具失败均保留；全部100题终态后再读取答案判分。

```sh
python3 tools/retail_eval/grade.py --sample samples/retail-gs1-zh-cn --results /path/to/terminal-results --output /path/to/new-score.json
```

固定分母100，失败和未回答不能剔除。Decimal精确相等允许等值数字表示；日期只规范化零点传输字符串。缺字段、漏行、重复标识、以零替换未知、错误受控值均失败。业务正确率与证据/生命周期单独报告。不使用题目专属宽容规则、不通过重试制造100%。
