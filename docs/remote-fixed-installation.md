# 远程固定制品安装

当前交付为未提交的实现，已接入 HTTP 安装入口与 Studio 的所选版本确认，但未部署，也未进行真实远程下载安装验收。现有实例中的远程版本仍保持不可安装，内置安装路径保留。

## 本轮实现

`installer/remote_bundle.py` 从已缓存的官方目录条目读取固定提交的清单、说明和验收记录，逐一核对 SHA-256。当前执行器只接受 `openbkn.ai/sample-install.v1`、一份归档、一个 MariaDB 镜像、一个原生 KN JSON。它沿用包内已有 alpha 安装清单与执行脚本，不把发布清单当作实例工作目录，也不转换业务模型。

当前制品约定：

- 包地址为官方仓库 GitHub Release 的 `sample-<sampleId>-v<version>/package.tar.gz`。
- 数据镜像位置为 `oci://ghcr.io/openbkn-ai/bkn-samples`，使用清单里的摘要形成不可变镜像引用。
- 只允许 GitHub 下载转向 `release-assets.githubusercontent.com`；不携带实例认证 token。
- 归档压缩大小最多 128 MiB，展开最多 512 MiB，单文件最多 128 MiB，文件数最多 10,000。只接受普通文件，拒绝路径穿越、链接、特殊文件与重名。
- 下载与解压发生在后台任务的私有临时目录，结束后清理。每次重试重新核对并加载原始固定包，不从最新目录选取替代版本。
- 平台版本、架构和能力需显式满足发布要求。目前执行器支持空格分隔的三段版本比较条件，如 `>=0.2.0 <0.2.1`；未知范围或扩展先拒绝执行。

包检查包括 alpha 清单、数据库名称及表数、内容目录、KN 身份、对象引用和包内版本说明摘要。完整原生 BKN/KN 校验、实际表绑定和场景结果仍由现有平台导入与验收流程完成；加载器本身不证明这些操作成功。

## 最小验收记录

验收记录目前为 JSON 对象，加载器要求以下字段：

| 字段 | 含义 |
| --- | --- |
| `sampleId` / `version` | 与目录及清单一致的样例身份 |
| `packageDigest` | 已验收包的 SHA-256 |
| `dataImageRef` | 已验收数据镜像的固定引用 |
| `freshInstallation` | 必须为布尔值 `true` |
| `checks` | 数据库、知识网络、能力、业务场景的实际通过记录 |

`checks` 为 `{ "name": "database|knowledge|capabilities|scenario", "passed": true }` 的数组，名称不得重复。记录可补充平台、架构、安装器镜像和日志位置。发布 PR 必须审核真实证据；字段校验只绑定经审核的声明，不能替代真实验收，不能把单元测试结果填成安装通过记录。当前没有生成正式验收记录。

## 固定安装任务

`installer/remote_installation.py` 将所选目录条目与执行器源摘要一次性保存到安装记录，再交给后台任务。说明文本及数据镜像摘要在文件检查通过后保存到同一记录。凭据由外层 worker 在内存中传递。

失败记录保留 `remoteRelease`，服务启动恢复也扫描远程样例的持久化任务；原始目录更新不会替换重试身份。执行器源或镜像摘要改变时拒绝重试。任务同时记录执行器源摘要及部署配置提供的完整安装器镜像引用，后者也固定镜像内 SDK。正式验收需使用并记录同一镜像。

部署需设置 Helm 的 `image.digest`、`platform.version`、`platform.capabilities`。缺少固定安装器镜像、平台版本或必要能力时，远程版本保持不可安装。HTTP 创建请求携带 `{version, manifestSha256}`，在持久化计划前按所选正式版本重新核对；原有空请求只用于内置样例。

数据库部署按任务传入固定镜像，部署前核对同名 StatefulSet、Service、Secret、PVC 上的样例、版本、镜像归属标记。冲突时拒绝写入；远程安装初始化失败保留数据卷，不自动删除。安装卡片以持久化记录显示已安装版本，即使目录缓存缺失也保留该记录。若正式目录撤回旧版本，拒绝对该版本发起重试。

## 接入前剩余事项

1. 评审两个仓库的工作区变更，再从固定提交构建真实制品和安装器镜像。
2. 生成真实发布清单，确认数据库镜像包含对应版本的完整数据与初始化脚本；验收后产生真实证明，不能用单元测试替代安装证明。
3. 在隔离实例完成首页操作的全新安装验收，之后才发布正式目录条目。升级与卸载不纳入当前范围。
