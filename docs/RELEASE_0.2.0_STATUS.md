## 实际验收范围

- 供应链：12 张业务表，知识网络对象与关系、14 个函数、8 个指标及绑定、4 个业务 Skill。生命周期新版本验证了表发现、对象／跨表／指标查询、函数调用和 Skill 发现。
- 世界杯：27 张业务表，原生 BKN 对象与关系、跨表查询及发布的 SQL 函数调用。
- 订单入门：产品与订单两张表，对象和关系导入、订单／产品关联查询；不声明可选函数、指标或 Skill。
- 三个样例：正式在线入口安装、卸载、重装成功；原记录资源在卸载后不存在，历史保留，旧卸载请求不能作用于重装资源。重装后的声明能力检查再次通过，均提供卸载入口。
- 已完成模型经 MCP 调用业务 Skill 的场景验收；新生命周期版本未重复进行模型驱动问答，不能将此前结果视为新版本的重新验收。

## 交付边界与使用前提

- 样例版本独立于平台版本。发布新版本不会自动升级已有安装；有归属记录的安装可先卸载再装新版本。
- 已安装旧包缺少归属记录时不能自动卸载，刷新目录不会改变这一事实。
- 卸载清除样例数据及用户修改，不支持原地升级、数据迁移或用户修改合并。
- 目录需管理员刷新，不是实时推送。没有缓存且无外网的新实例可导入完整包；共享数据库补丁需要产品预先提供样例数据库服务，样例安装不再依赖独立数据镜像。
- 运行验收覆盖 arm64；amd64 镜像构建不等于已完成 amd64 运行验收。
- 供应链删除知识网络时，平台代理同步可能暂时未完成；任务失败后可使用「继续卸载」。
- PVC 的实际回收受 StorageClass reclaimPolicy 控制，Retain 存储需管理员另行回收。

设计见 [总体设计](DESIGN.md)，作者更新样例见 [开发指南](SAMPLE_DEVELOPMENT_GUIDE.zh-CN.md)，用户更换版本见 [卸载与重装](sample-uninstall.md)。发布凭证保存在各独立版本目录和 GitHub Release；旧版本固定提交中的证据可继续读取。
