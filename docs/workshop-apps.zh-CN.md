# 样例自带的 Workshop 应用

样例可以自带 Workshop 应用，安装完成后直接在样例自己的知识网络上打开使用。

## 添加应用

1. 安装样例后，在应用工坊里基于样例的知识网络建好应用，例如用“资源排程工作台”向导。
2. 在应用列表里导出。导出的是应用草稿，文件名为 `<id>.app.yaml`。
3. 保存为 `samples/<样例>/workshop/apps/<名称>.app.yaml`。其他语言的样例各带一份，在该样例的网络上建，文案用该语言。

安装器逐个检查：`apiVersion` 为 `workshop.openbkn.ai/v1`；应用有名称（不超过 128 个字符）；`dependencies.knowledgeNetwork.id` 是样例的知识网络；至少有一个页面。同一样例的应用不能重名。

对象类和行动按 ID 引用，在样例的每次安装中都相同。工具箱和工具的 ID 每次安装都会变。规则函数同时记录了 `boxName` 和 `toolName`，找不到原 ID 时 Workshop 按名称调用，所以工具箱名和工具名要保持不变。模型工具只按 ID 调用，样例应用不要使用。

## 安装与卸载

- 安装包带上 `workshop/` 目录，并声明能力 `sample.workshop-apps`；不支持该能力的样例服务会在下载前拒绝这个包。
- 平台检查通过后，安装器在样例网络上逐个创建应用，把文件写为草稿并发布，应用的页面即可从应用列表打开。创建的应用 ID 记在安装记录（`workshopApps`）里，每次变更后立即写入。
- 再次安装或重试失败的安装时，先删除记录中的应用和样例网络上的同名应用，再重新创建。
- 卸载时与样例的函数、Skill 一起删除记录中的应用。
- 安装的管理员需要有创建 Workshop 应用的权限。Workshop 属于专业版。
