# FIBO 0.2.4 源码与实际验收

本 PR 已从旧版目录登记调整为中英文 **0.2.4 源码与验收记录**。每语20表、78,356条虚构记录、20对象、29关系、3分组、3个原始事实重算函数、2个已记录快照指标、1个只读调查Skill，要求 **OpenBKN >=0.2.1 <0.3.0**。金融范围为交易后运营、估值和限额调查，不是全量FIBO、官方净值或监管计量。

## 版本与发布状态

- 英文0.1.3/中文0.1.4的已发布制品是不含后续能力的历史包，其旧100/100开发回归不证明0.2.4通过。
- 本PR不登记上述旧包，不修改主线catalog内容或sequence，也不改写旧Release、保留tag或元数据；旧版sample.json/verification.json仅按原字节保留，作为标准构建器要求的已审核发布基线，不新增其目录发现。原目录合并冲突已处理，GS1及其他主线条目保持完整。
- 本次把已验证的306份冻结源码复制到独立工作目录，随后只修正文档、Skill和本体分析契约，以及生成器中对应说明。数据、题库、金标、运行时函数和注册逻辑均与已验证候选相同；逐文件变化另见[源版本对应](financial-fibo-acceptance/candidate-0.2.4/source-adoption.json)。说明变更不冒充已做过新模型问答。
- 当前仍未发布0.2.4。源码合并后再从固定提交构建/核验精确候选、发布不可变制品并另开目录PR；本源码PR不得被解释为最终线上安装或全量业务认证。
