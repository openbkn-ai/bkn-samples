# 金融双语样例评审与修复记录

本轮按金融行业专家视角，由独立评审代理完成首轮评审和修复后复验。此为专家视角模拟，不代表真人行业资质或机构背书。范围是 PRD 批准的证券投资组合交易后控制，交付保持本地。

- [首轮评审原文](financial-fibo-expert-review.zh-CN.md)：7 项主要问题、4 项适度改善项及不应扩张的范围。
- [独立复验原文](financial-fibo-expert-recheck.zh-CN.md)：原始 CSV 独立计算、错误注入、双语和扩量质量结果。

## 逐项修复

| 评审问题 | 处理 | 验收证据 |
|---|---|---|
| 周末成交/结算/报价、到期前判失败 | 使用明示的虚构周一至周五/T+2；月末用此前工作日报价和定盘；失败/部分结算不早于约定日 | 独立检查三类周末记录均为 0；日历负向测试；原生 BKN 校验 |
| 三月全部不结算 | 增加正常预期结算、部分/持续失败和 256 条前期指令预测恢复；所有预测仍标计划 | 二月当前聚合不消费三月恢复；正常组合三月应收回到 0 |
| 未来知识、币种及来源校验盲区 | 对全部含 known/view 字段的表统一校验；核对工具/开仓/成交/指令/持仓币种、资产单位/报价乘数；拒绝未发布 FX | 原 5 个 FALSE PASS 全被拒绝；另补报价口径、来源和知识日期控制 |
| 单事件 SQL 假设 | 增量事件按指令汇总、日期与知识截止过滤，最新有效事件决定状态；日期加指令内顺序排序 | 6,400 笔实际成交聚合前后不增笔数；ACK 不重复合约额，重复转移被拒绝 |
| 本体语义薄弱 | 20 个对象分别补业务定义，关键字段补公式、期间、币种、分母、计划/实际与空值语义 | 中英文原生 BKN 校验；独立抽查口径 |
| 答案解释复述问题 | 全部 100 题改为实际证据结论与必要口径；专属复杂题移除不相关的通用说明 | 中英文解释均不再重复题目；人读答案同步更新 |
| 违规到交易/结算闭环不完整 | FIN-080 明确存量与当月变动；FIN-088 连通限额、指令、失败/累计结算与贡献金额 | 独立重算 PF-046 原始构成 2002.406553 → 2002.41 USD；负损益锚点 -132.86 |
| hard 题复杂性不足 | 引入成交日已知 FX 曲线、多事件月末聚合、完整违规证据链；维持 30/40/30 分配 | 中英文各 100 题、覆盖全部 20 表/29 关系 |
| 阈值边界缺少测试 | 对金额与比例分别测试等于、低一单位、高一单位、未知 | 等于不超限，严格大于才超限，未知不补零 |
| FX 曲线存在未利用记录 | FIN-019 按每笔实际成交选当时已发布的最近观察，不只读取月末 15 个定盘 | 单币种/方向分组使用多项历史定盘，输出日龄及美元金额 |
| NULL 角色审计漏报风险 | FIN-009 显式 IS NULL；独立删除一个发行方实体验证能发现两项工具异常 | NULL 审计反例通过 |
| 复验新增：事件尚未发生却提前知晓 | 实际订单/成交/结算事件在本样例按发生日入账，禁止提前知晓；计划仍允许事前假设 | 新增结算提前知晓、成交提前知晓两项负向控制 |

## 数据规模和业务差异

每种语言共 **78,356 条**，覆盖 **200 个组合、每组合八项持仓/四家发行方、五个月快照**。对象与关系保持 20/29，没有用增加空实体或运行能力凑覆盖。

有 8,000 笔成交、16,176 条结算事件、8,000 项持仓快照、8,000 项估值和 5,000 项限额评估。两种语言合计 156,712 条记录。所有组合有独立名称和不同的工具/期初数量/成本轮廓；发行方、工具、价格和经纪商跨组合共享。

扩量同时增加了错开日期、确认/转移/恢复、不同未结算原因、正负已实现与未实现损益、共享价格缺陷传播、当前和未来限额的差异。[中文数据复杂度证据](../samples/financial-fibo-zh-cn/verification/data-complexity.json)记录数量及符号分布。

## 最终本地验证

- 中英文原生 BKN 校验通过，无错误和警告。
- 中英文各 100 题确定性回放通过，难度为 30 easy/basic、40 intermediate、30 hard/complex。
- **55 项财务语义、负向注入、双语与回归检查全套通过**。复验原文记录当时的 53 项加两项定向检查；最终全套 55 项日志保存在各语言 `verification/negative-controls.txt`。
- 逐项重算每语言 8,000 个持仓、8,000 个估值、5,000 个评估；未用生成器重新生成预期答案来冒充验证。
- 各语言 `verification/local-evaluation.json` 绑定数据锁、模型合同、全部 BKN 文件、验证代码、问题和答案摘要。

本地 SQL 回放不是平台或智能体问答准确率。平台导入、数据资源绑定和独立智能体/MCP 验收尚需各自实际执行。此轮没有发布安装包、更新线上目录、引入指标/函数/Skill 或推送 Git 提交。
